[[PLAN]] **Selecting "Custom"**: opens a two-input dialog (light-mode hex + dark-mode hex, both required)
       - Applies inline `style="color: light-dark(#light, #dark)"

no, this should be a single hex input, with two swatches after it that show the generated light/dark values.  it shouldn't be an inline style, it should be:
```
<p class="pfx-text-color-custom">hello</p>
```
and may require a data attribute or something so that a single editor can have multiple custom colors or we could do:
```
p class="pfx-text-color-custom" style="color:light-dark(--tinymce-custom-color-1);"
```
or something similar. we need to make sure we capture/retain the single input value and display the derived values. I prefer not to inline the derived values because that could break accessibility again.
