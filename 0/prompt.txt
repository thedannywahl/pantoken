**The transform steps:**

1. **`scripts/component-styles.ts`** (`/Users/dwahl/Scripts/pantoken/formats/components/scripts/component-styles.ts`): reads each source `.css`, and for each of the three themes `["rebrand","canvas","canvasHighContrast"]` runs PostCSS with the single plugin `themeCustomMedia({ theme })`. ### 2. Multi-theme component stylesheet generation for the docs demos (commit b399069)

The shipped `components.css` is lowered to a single theme (rebrand), so its `@media (--theme-*)` overrides are pruned and the docs' runtime theme toggle (`&lt;html data-pantoken-theme="…"&gt;`) can't bring them back. The docs generate their own multi-theme sheet:

- **`/Users/dwahl/Scripts/pantoken/docs/scripts/lib/scope-components.ts`** — `scopedComponentsCss(prefix="instui")`. Calls `componentsCss({ prefix, theme })` from `@pantoken/components` for each theme, emits the rebrand rules unscoped as the base, then **diffs** each of `["canvas","canvasHighContrast"]` against the base at PostCSS-node granularity; the theme-only extra rules get their selectors re-scoped under `:root[data-pantoken-theme="&lt;theme&gt;"]`. It throws if a theme-only delta is a non-`rule` at-rule (unsupported nesting).

- **`/Users/dwahl/Scripts/pantoken/docs/scripts/components-sheet.ts`** (new in this commit) — `writeComponentsSheet()` writes the result to **two outputs**:
  1. `/Users/dwahl/Scripts/pantoken/docs/.vitepress/theme/generated/components.css` — imported by the docs theme (`docs/.vitepress/theme/index.ts`, which the commit changed from importing `@pantoken/components/components.css` to `./generated/components.css`). Powers the inline CSS-API `@example` previews.
  2. `/Users/dwahl/Scripts/pantoken/docs/public/demos-assets/components.css` (copy) — loaded by the `/play` runner iframes via `demos.ts`'s `cssUrls`.

- **`/Users/dwahl/Scripts/pantoken/docs/scripts/demos.ts`** now imports and calls `writeComponentsSheet()` (replacing an inline `writeFileSync(scopedComponentsCss(...))`). `demos.ts` runs as part of the `docs:assets` npm script.
