## 2. Concrete class-name vocabulary

**Naming convention:** each component has a base class `instui-&lt;name&gt;`, and variants are separate dash-prefixed modifier classes applied alongside it, e.g. `class="instui-button -color-secondary -size-lg"`. The `instui-` prefix is configurable (a builder can emit no prefix, giving `class="heading -level-h1"`), but the docs site uses the default `instui-` prefix.

**Base component classes** (one per file in `dist/`):
`instui-alert`, `instui-avatar`, `instui-badge` (+ `instui-badge-wrapper`), `instui-billboard`, `instui-breadcrumb`, `instui-button`, `instui-byline`, `instui-calendar`, `instui-checkbox`, `instui-close-button`, `instui-context-view`, `instui-file-drop`, `instui-form-field` (+ `instui-form-field-group`, `instui-form-field-messages`, `instui-form-field-message`), `instui-heading`, `instui-img`, `instui-in-place-edit`, `instui-input-group`, `instui-link`, `instui-list`, `instui-menu`, `instui-metric`, `instui-modal`, `instui-number-input`, `instui-pagination`, `instui-pill`, `instui-popover`, `instui-progress` (+ `instui-progress-value`), `instui-progress-circle`, `instui-radio` (+ `instui-radio-input-group`), `instui-range-input` (+ `instui-range-input-value`), `instui-rating`, `instui-simple-select`, `instui-side-nav-bar`, `instui-spinner`, `instui-table`, `instui-tabs`, `instui-tag`, `instui-text`, `instui-text-area`, `instui-text-input`, `instui-toggle-details`, `instui-toggle-group`, `instui-tooltip`, `instui-tray`, `instui-tree-browser`, `instui-truncate`.

**Card:** there is **no** `instui-card` in the component library. `.instui-card` is a **docs-only** demo surface defined at `/Users/dwahl/Scripts/pantoken/tools/demo/assets/card.css` (published as `@pantoken/demo/card.css`). It's a padded, rounded, elevated view surface. If you want a card look from the shipped library, compose `instui-view` + a `instui-bg-*` + `instui-border-radius-*` + an `instui-elevation-*` utility (see below).

- Foreground/text color: `instui-fg-*` (same value set as `bg`)

- Spacing: margin `instui-m-{0,2xs,xs,sm,md,lg,xl,2xl,auto}` with directional variants `mt/mb/ms/me/mx/my` (and long forms `margin-`, `margint-`, etc.); padding `instui-p-*` with `pt/pb/ps/pe/px/py` (and `padding-*` long forms)
- Display: `instui-display-{block,inline,inline-block,flex,inline-flex,none}`
- Typography: `instui-font-family-{base,heading,code}`, `instui-font-weight-*`, `instui-line-height-*`, `instui-text-align-{start,center,end,justify}`
