### 6. Horizontal divider / rule
**No standalone divider component or utility exists.** Three partial patterns instead:

2. Inside prose/markdown content: raw `&lt;hr&gt;` styled only within `.instui-prose` scope — `border-top: var(--instui-border-width-sm) solid var(--instui-color-stroke-base); margin: var(--instui-spacing-space-lg) 0;` (`formats/components/src/rules/prose.ts:101-105`). Not applied outside `.instui-prose`.
3. Inside disclosure groups: `.instui-toggle-group &gt; :not(summary)` gets `border-block-start: var(--instui-border-width-sm) solid var(--instui-component-toggle-group-border-color)` as a separator between header and content (`formats/components/src/components/toggle-group.css:59-62`).

For a general-purpose divider outside those contexts, the idiomatic approach given this codebase's token system is to compose it from primitives directly (there's precedent for exactly this in prose's `hr` rule): `border-top: var(--instui-border-width-sm) solid var(--instui-color-stroke-base);` with `margin` from the spacing utility scale (`.instui-mt-md`/`.instui-mb-md`, documented in `docs/guide/components.md:134-144`) — no bespoke color/width values needed. There is no `-border-top`/`-border-bottom`-style modifier on `.instui-view` today (View has `-border-width-*` which draws all four sides, not one).
