There is no `.husky` directory and no `husky`/`lefthook`/`simple-git-hooks` config anywhere in the repo. Hooks are managed by **vite-plus** (`vp`) itself via `.vite-hooks/`:

```

```

Source hook files (what you edit) live at repo root in `.vite-hooks/`; the files actually installed under `.vite-hooks/_/{pre-commit,pre-push,commit-msg}` are thin dispatchers (`#!/usr/bin/env sh\n. "$(dirname "$0")/h"`) that source a shared `h` helper and execute the source files below.

**`.vite-hooks/pre-commit`** (verbatim, full file):
```

```

**`.vite-hooks/commit-msg`** (verbatim, full file):
```

```

**`.vite-hooks/pre-push`** (verbatim, full file — this is where i18n drift is gated locally):
```
# Block a push that changes a publishable package with no covering changeset (bypass: --no-verify).
vp run release:coverage
# Guard against stale i18n bundle caches when strings.ts or i18n package files changed.
if git diff --name-only "@{upstream}...HEAD" 2&gt;/dev/null | grep -qE '^(packages/i18n/|renderers/web-components/src/lib/strings\.ts)'; then
  vp run i18n:check:drift
fi
# Block a push that introduces new fallow findings (dead code / complexity) in the changed files,
# measured against the upstream branch (falls back to origin/main). Scoped + fast; bypass: --no-verify.
vp exec fallow audit --base "$(git rev-parse --abbrev-ref --symbolic-full-name '@{upstream}' 2&gt;/dev/null || echo origin/main)"
# Gate on Snyk Code (SAST): Snyk has no GitHub App here, so CI can't run it — this is the enforcement
# point for code-security findings. Blocks on a high-severity finding; skips (with a warning) when
# Snyk isn't authenticated, so a contributor without a Snyk account isn't blocked. Bypass: --no-verify.
vp run snyk:code
# Catch Markdown formatting issues locally before they fail CI.
vp run lint:markdown
# Property-based tests run at default iterations (100) in the CI `test` job on every PR. No separate
# pre-push gate needed — fast-check failures surface in CI before merge.
```

Important: **there is no docs-drift check in any git hook** — only `i18n:check:drift` (for `packages/i18n`) is hook-gated, and only conditionally (only when `packages/i18n/` or `renderers/web-components/src/lib/strings.ts` changed since upstream). `docs:check:drift` never runs in a hook.
