## 3. Icon glyphs — how icon values are represented

Icons are stored as inline SVG (`&lt;path d&gt;`, plus line/circle/rect/polyline/polygon) that gets percent-encoded into the data URI above. They are NOT unicode glyphs at the token level. Downstream consumers decode back to SVG:
- **`/Users/dwahl/Scripts/pantoken/formats/icons/src/index.ts`** — `@pantoken/icons`, decodes `dataUri` → inline `svg`, exposes `viewBox`, `bidirectional`, `source` ("custom" | "lucide").

- Unicode only appears in the icon-FONT build (**`/Users/dwahl/Scripts/pantoken/formats/icon-font/src/build.ts`**), which assigns Private Use Area codepoints (U+E000+) when generating a font — a separate output format, not the token value.
