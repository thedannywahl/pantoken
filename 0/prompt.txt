## 3. Register-everything vs. register-selected — selection exists, but only at the JS/element level, not as separate importable files

- Default: importing `@pantoken/web-components` (ESM) auto-registers **everything** — `register()` is called unconditionally at module load (`renderers/web-components/src/index.ts:453`: `register();`).
- Selective: `register(customElements, { only: ["date-time-input"] })` registers a subset, expanding transitive deps via the (unexported) `NESTED_DEPS` (`src/index.ts:383-449`, especially `398`, `446-448`).
- There are **no per-component JS entry files** — `scripts/build-entries.ts` (line 1-3 doc comment) only emits per-record **CSS**, never per-component JS modules. So you cannot build a jsDelivr combine URL that pulls in just `&lt;instui-alert&gt;`'s JS the way you can for `alert.css`. Selection is purely a runtime API call (`only: [...]`), not a file-level "import just this one" story. This is the key constraint that differs from the Components CSS tab.
- The IIFE build always registers **all** elements — it has no `only` equivalent (it's a raw `&lt;script src&gt;`, no room to pass options before it runs). `PantokenWebComponents` global exposes `register`/`iconSvg`/etc. so a consumer *could* re-invoke `register(customElements, { only: [...] })` themselves after the auto-run already registered everything, but that's redundant/pointless since auto-registration already ran on load.

`docs/guide/cdn.md:55-96` ("## Web components" section) already documents both forms with exact URLs:

  and the selective form:
  ```html
  &lt;script type="module"&gt;
    import { register } from "https://esm.sh/@pantoken/web-components";
    register(customElements, { only: ["date-time-input"] });
  &lt;/script&gt;
  ```
  Note it uses `esm.sh`, not jsDelivr, for the ESM path — presumably because jsDelivr's `/npm/` ESM resolution of bare-import dependencies (`@pantoken/components`, `@pantoken/icons`) is less reliable than esm.sh's resolver; jsDelivr is used only for the CSS `&lt;link&gt;` and the IIFE `&lt;script src&gt;`.

- Classic script tag, lines 84-95:
  ```html
  &lt;link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@pantoken/css/dist/style.css" /&gt;

  ```

`docs/conventions/web-components.md` is an internal engineering-convention doc (architecture notes: shadow-CSS `?inline` pattern, spacing mixin, Invoker Commands API, register/prefix mechanics) — not consumer CDN docs, but useful background for `NESTED_DEPS`/prefix behavior if you want to expose those controls in the picker.
