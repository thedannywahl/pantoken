## Summary conclusion

No `--instui-*` token is ever animated as a custom property. Every animation and transition in the codebase animates a regular, natively-registered CSS property (`outline-color`, `outline-offset`, `transform`, `opacity`, `background-color`, `border-color`, `width`, `filter`, `inset-inline-start`, `color`, plus `overlay`/`display` for discrete transitions). These read `--instui-*` tokens through `var()`, but the interpolation happens on the CSS property, not on the custom property. That means stripping the token-sheet `@property` registrations is safe with respect to animation. The single custom property that IS interpolated (`--value`) is component-local and registered in the component's own CSS, not the token sheet.

## 2. Focus-outline detail (as requested)

In `formats/components/src/declarations/focus.ts`:
- Resting rule (line 85-87): sets `outline`, `outline-offset: 0`, and `transition: var(--instui-focus-outline-transition)`.
- The transition value is defined at line 66 as `"outline-color 0.2s, outline-offset 0.25s"` — it names the regular properties `outline-color` and `outline-offset`.
- `:focus-visible` (lines 89-93) then changes `outline-color`, `outline-offset`, `border-radius`, each reading an `--instui-focus-outline-*` token via `var()`.

So focus-outline interpolates `outline-color` and `outline-offset` (native CSS properties). It does NOT interpolate any `--instui-*` custom property. The `@property` for `--instui-focus-outline-color`, `--instui-focus-outline-offset`, etc. is NOT load-bearing for this animation. `outline-color` is a natively-registered animatable property, so the color transition works regardless of whether the token has an `@property`.

## 3. Badge detail (as requested)

In `formats/components/src/components/badge.css`, `@keyframes pantoken-badge-pulse` (lines 36-45) interpolates `transform: scale()` and `opacity` on the `-pulse::before` ring. ## 4. The one animated custom property — and why it's safe

`--value` in `formats/components/src/components/progress-circle.css`:
- Registered by the component itself at lines 35-39: `@property --value { syntax: "&lt;number&gt;"; inherits: true; initial-value: 0; }`.
- It is a bare local property (`--value`), NOT an `--instui-*` token.
- Confirmed NOT present in the token sheet: `grep -c "@property --value" formats/css/dist/style.css` → `0`.
- Its `@property` ships in the component's own dist: `formats/components/dist/progress-circle.css` contains `@property --value{syntax:"&lt;number&gt;";inherits:true;initial-value:0}`.

So its registration lives entirely in component CSS. Stripping the token sheet's `@property` blocks has no effect on it.
