`colorUtilitiesCss` now emits `.--color-<name>` as an alias of `.--text-<name>` (same declaration, either class name works). `@pantoken/components`'s semantic text-color utilities (`--text-danger`, `--text-secondary`, ...) gain the matching `--color-*` class for free.
