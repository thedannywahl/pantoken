Add `buildTheme` (plus `buildThemeCss`/`buildThemeJs`), built on the new `@pantoken/cdn` package,
to build `theme.css`/`theme.js` content for a chosen CDN provider (jsDelivr, unpkg, esm.sh, or a
custom provider), an optional pinned version, and a caller-supplied asset list — so consumers
aren't limited to the default `@pantoken/css`/`@pantoken/components`/`@pantoken/interactions`
assets and can pull in other pantoken (or third-party) packages via the CDN. The committed
`templates/theme.css`/`theme.js` (and their static `dist/` copies) are unchanged: they're now
generated by `buildTheme({ provider: "jsdelivr" })` instead of hand-authored, but the output is
byte-for-byte identical.

The comment prose baked into theme.css/theme.js is now translation-ready: it's sourced from
`src/i18n.json` (same pattern as `@pantoken/web-components`'s `src/i18n.json`), and `buildTheme`'s
new `strings` option lets a caller supply translated text, falling back to the English default
(`ENGLISH_THEME_STRINGS`) for any key it omits.
