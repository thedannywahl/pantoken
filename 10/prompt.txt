this skin is not following the convention recommended by the guides:
1. Duplicate the `default` folder in `modules/oxide/src/less/skins/ui/` and rename it.
2. Open `modules/oxide/src/less/skin/ui/<your-skin-name>/skin.less`.
3. Open a Less file from the theme folder (e.g., `modules/oxide/src/less/theme/globals/global-variables.less`) and copy a variable to modify.
4. Paste the variable into the `skin.less` file.
5. The updated `skin.less` should look like this:
```less
@import 'src/less/theme/theme';

//
// Place your variables here
//

@background-color: red;
```
