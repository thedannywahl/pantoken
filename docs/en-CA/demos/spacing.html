Spacing

Per-side classes on the spacing scale — m/p for margin/padding, an optional logical side (t/b/s/e/x/y), then a step (0, 2xs…2xl, plus auto for margin). Every class also has a fully long, word-spelled twin — --mb-sm is the same rule as --margin-bottom-small.
