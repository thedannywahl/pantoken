# تابع: toThemeKey()

> **toThemeKey**(`name`): `string`

<span class="instui-pill -color-danger pantoken-doc-tag">تجربی</span>

## پارامترها

### name

`string`

## مقدار بازگشتی

`string`

## نمونه

```ts

toThemeKey("--instui-color-background-brand"); // "colorBackgroundBrand"
```
