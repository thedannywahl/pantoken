# postcss

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/postcss` — un connector de PostCSS que expandeix una regla at `@pantoken;` en la full d'estils de tokens
complet d'Instructure (registres `@property` + declaracions). Escriviu `@pantoken;` on
vulgueu que els tokens estiguin definits, i el connector els substitueix en temps de construcció.
