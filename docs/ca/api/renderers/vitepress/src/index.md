# vitepress

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/vitepress` — tema un lloc VitePress amb tokens d'Instructure.

La tematització de VitePress és impulsada per les variables CSS `--vp-*`. Això les apunta a `var(--instui-*)`, així
que deixar la sortida a `.vitepress/theme/custom.css` (juntament amb `@pantoken/css`, que defineix
les propietats personalitzades) re-tematitza la documentació amb l'aspecte d'Instructure mentre la llum/fosc continua fluint
a través dels mateixos tokens.
