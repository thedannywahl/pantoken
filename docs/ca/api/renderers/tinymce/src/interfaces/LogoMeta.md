# Interfície: LogoMeta

Metadades per a un actiu de logotip disponible.

## Propietats

### product

> **product**: [`Product`](../type-aliases/Product.md)

El producte al qual pertany el logotip.

***

### layout

> **layout**: `LogoLayout`

El disseny.

***

### colorMode

> **colorMode**: `LogoColorMode`

El tractament del color.

***

### name

> **name**: `string`

L'arrel del token/nom, per exemple `"canvas-horizontal-full-color"`.

***

### path

> **path**: `string`

El camí dins de `assets/logos`, per exemple `"canvas/horizontal-full-color.svg"`.
