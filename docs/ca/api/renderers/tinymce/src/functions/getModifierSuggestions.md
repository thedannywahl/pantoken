# Funció: getModifierSuggestions()

> **getModifierSuggestions**(`entryName`, `prefix?`): `object`[]

Obté totes les suggerències de modificadors per a un component/utilitat, filtrat per un prefix opcional.
Retorna matriu d'objectes `{ name, prop, value?, description }`.

## Paràmetres

### entryName

`string`

### prefix?

`string`

## Retorna

`object`[]
