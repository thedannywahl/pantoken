# svelte

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/svelte` — Ajudants de Svelte sobre `@pantoken/web-components`.

`icon` és una acció de Svelte que representa un glifo d'Instructure a un element. `readToken` llegeix un
valor `--instui-*` resolt (segur per a SSR). Els elements personalitzats també funcionen directament una vegada `register()`
s'ha executat.
