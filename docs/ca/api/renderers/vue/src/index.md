# vue

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/vue` — un connector Vue sobre `@pantoken/web-components`.

`install` registra els elements personalitzats i diu al compilador de Vue que tracti les etiquetes `instui-*` com a
elements personalitzats. `readToken` llegeix un valor `--instui-*` resolt (SSR-segur).
