# Funció: Icon()

> **Icon**(`__namedParameters`): `ReactNode`

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

Renderitza una icona d'Instructure com a l'element personalitzat `&lt;instui-icon&gt;`.

## Paràmetres

### \_\_namedParameters

[`IconProps`](../interfaces/IconProps.md)

## Retorna

`ReactNode`

## Exemple

```tsx
import { Icon } from "@pantoken/react";

<Icon name="check-mark" size="1.25rem" color="var(--instui-color-text-success)" />;
```
