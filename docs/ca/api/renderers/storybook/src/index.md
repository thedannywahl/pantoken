# storybook

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/storybook` — un tema de Storybook construït a partir dels tokens d'Instructure.

[pantokenStorybookTheme](functions/pantokenStorybookTheme.md) retorna un objecte simple amb forma de `ThemeVars` (així `@storybook/theming`
es manté com un homòleg opcional) amb colors resolts concretament de l'IR. Passa'l al tema
`manager`/`preview` de Storybook.
