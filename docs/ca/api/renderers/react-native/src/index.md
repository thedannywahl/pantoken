# react-native

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/react-native` — tokens de disseny de Instructure com a objectes amigables amb `StyleSheet`
de React Native. React Native no té variables CSS, per la qual cosa els tokens es resolen completament a valors concrets:
els colors es mantenen com a cadenes hex, les dimensions es converteixen en números (dp) i es exclouen les icones.
