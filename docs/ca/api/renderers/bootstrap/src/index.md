# bootstrap

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/bootstrap` — tema Bootstrap 5 amb tokens d'Instructure.

Apunta les variables CSS `--bs-*` de Bootstrap a `var(--instui-*)`. Posa-la juntament amb
`@pantoken/css` i els components de Bootstrap adopten l'aspecte d'Instructure mentre es mantenen els temes
per mitjà de les mateixes propietats personalitzades.
