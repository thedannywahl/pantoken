# angular

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/angular` — Ajudants angulars sobre `@pantoken/web-components`.

Crideu [registerPantokenElements](functions/registerPantokenElements.md) durant l'inici, i afegiu `CUSTOM_ELEMENTS_SCHEMA` al
component/mòdul que utilitza `&lt;instui-icon&gt;`. [readToken](functions/readToken.md) llegeix un valor `--instui-*` resolt.
