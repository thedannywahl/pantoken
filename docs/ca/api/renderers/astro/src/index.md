# astro

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`@pantoken/astro` — Integració d'Astro / Starlight per a pantoken.

[InstUI](functions/InstUI.md) és un plugin Starlight que injecta l'full d'estils de pantoken (i qualsevol CSS del plugin,
per exemple, un anell de focus) a la capçalera de la pàgina. Portualitza l'enfocament de `starlight-theme-instui` a la
canalització `@pantoken/css` compartida, de manera que ja no porta el seu propi resolutor de tokens.
