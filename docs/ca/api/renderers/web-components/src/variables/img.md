# Variable: img

> `const` **img**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alfa</span>

`&lt;instui-img&gt;` — un `&lt;img&gt;` amb estil de token construït a partir de `src`/`alt`. `constrain` mapeja a `-constrain-&lt;value&gt;` (per exemple `cover`, `contain`) i `display="block"` a `-display-block`.

## Exemple

```html
<instui-img src="/hero.jpg" alt="Campus" constrain="cover" display="block"></instui-img>
```
