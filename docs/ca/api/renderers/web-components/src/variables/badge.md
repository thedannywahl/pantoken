# Variable: badge

> `const` **badge**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alfa</span>

`&lt;instui-badge&gt;` — una insígnia petita de recompte/estat. L'atribut `variant` es mapeja al modificador `-color-&lt;variant&gt;`; el contingut amb slot és el recompte o l'etiqueta.

## Exemple

```html
<instui-badge variant="danger">9</instui-badge>
```
