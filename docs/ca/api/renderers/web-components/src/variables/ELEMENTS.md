# Variable: ELEMENTS

> `const` **ELEMENTS**: readonly \[`"icon"`, `"button"`, `"alert"`, `"badge"`, `"pill"`, `"tag"`, `"avatar"`, `"spinner"`, `"progress"`, `"metric"`, `"rating"`, `"progress-circle"`, `"icon-button"`, `"toggle-button"`, `"truncate"`, `"img"`, `"side-nav-bar"`, `"tree-browser"`, `"calendar"`, `"tooltip"`, `"modal"`, `"context-view"`, `"popover"`, `"tray"`, `"in-place-edit"`, `"drilldown"`, `"pages"`, `"drawer-layout"`, `"date-input"`, `"date-time-input"`\]

<span class="instui-pill -color-warning pantoken-doc-tag">Alfa</span>

Els noms d'elements base (sense prefix) que registra aquest paquet. [register](../functions/register.md) crea una etiqueta per nom sota la seva opció `prefix` — `icon` → `&lt;instui-icon&gt;` per defecte, o `&lt;x-icon&gt;` per a `{ prefix: "x" }`. Un prefix sempre s'aplica (un nom d'element personalitzat ha de contenir un guió), de manera que un prefix buit o nul retorna al `instui` per defecte.
