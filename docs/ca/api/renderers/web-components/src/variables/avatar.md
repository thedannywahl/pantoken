# Variable: avatar

> `const` **avatar**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-avatar&gt;` — un avatar circular (o rectangular). `variant` es mapeja a `-color-&lt;variant&gt;`, `size` a `-size-&lt;size&gt;`, i `shape="rectangle"` a `-shape-rectangle`; el contingut amb slot són les inicials, o un `&lt;img&gt;` (utilitzeu una URL absoluta/CDN `src`) per mostrar una foto.

## Example

```html
<instui-avatar size="lg" margin="small">JS</instui-avatar>
<instui-avatar shape="rectangle" variant="green" margin="small">AB</instui-avatar>
```
