# Variable: pill

> `const` **pill**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-pill&gt;` — una píndola d'estat compacta. L'atribut `variant` es mapeja al modificador `-color-&lt;variant&gt;`; el contingut ranurat és l'etiqueta.

## Example

```html
<instui-pill variant="success">Active</instui-pill>
```
