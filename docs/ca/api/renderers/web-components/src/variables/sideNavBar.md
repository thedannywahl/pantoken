# Variable: sideNavBar

> `const` **sideNavBar**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-side-nav-bar&gt;` — la carcassa estilitzada d'un rail de navegació vertical. `minimized="true"` afegeix el modificador `-minimized` (rail col·lapsat); el consumidor ranura els elements de navegació.

## Example

```html
<instui-side-nav-bar>
  <a href="/dashboard">Dashboard</a>
  <a href="/courses">Courses</a>
</instui-side-nav-bar>
```
