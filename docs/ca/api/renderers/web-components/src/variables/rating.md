# Variable: rating

> `const` **rating**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-rating&gt;` — una valoració per estrella amb `role="img"`. `value` és el nombre d'estrelles plenes, `max` el total (per defecte 5), i `label` substiteix el nom accessible (per defecte a `value/max`). Les estrelles es renderitzen com glifos SVG en línia (sòlid = ple), dimensionats al text.

## Example

```html
<instui-rating value="4" max="5" label="4 out of 5 stars"></instui-rating>
```
