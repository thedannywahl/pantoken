# Variable: iconButton

> `const` **iconButton**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-icon-button&gt;` — un botó quadrat només amb icona. `label` es converteix en `aria-label` del botó; el contingut ranurat és el glyph (per exemple, un `&lt;instui-icon&gt;`).

## Example

```html
<instui-icon-button label="Close">
  <instui-icon name="x"></instui-icon>
</instui-icon-button>
```
