# Variable: toggleButton

> `const` **toggleButton**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alfa</span>

`&lt;instui-toggle-button&gt;` — un botó de dos estats. `pressed="true"` es reflecteix al `aria-pressed` del botó; el contingut ranurat és l'etiqueta.

## Exemple

```html
<instui-toggle-button pressed="true">Bookmarked</instui-toggle-button>
```
