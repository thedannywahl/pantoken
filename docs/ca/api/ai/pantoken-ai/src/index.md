# pantoken-ai

<span class="instui-pill -color-warning pantoken-doc-tag">Alfa</span>

`@pantoken/ai` — actius d'agent orientats al consumidor per a projectes que *utilitzen* pantoken (no per a
desenvolupament de pantoken en si).

Inclou un `AGENTS.md`, un `llms.txt`, fitxers de regles d'editor/agent (Cursor, Copilot, Windsurf), i
habilitats de Claude Code (`init-pantoken`, `create-pantoken-app`), més [installAgentAssets](functions/installAgentAssets.md) /
[scaffoldAndInit](functions/scaffoldAndInit.md) / la CLI `pantoken-ai` per deixar-les en un repositori de consumidor als
camins convencionals.
