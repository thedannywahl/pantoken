# Referència de l'API

La referència de l'API pantoken abarca biblioteques principals, emissors de format, objectius de plataforma, renderitzadors,
connectors de bundler i eines de disseny.

## Comença aquí

| Àrea | Descripció |
| --- | --- |
| [CSS API reference](/ca/api/css/) | Classes de component, utilitats, regles, declaracions i comportament CSS recolzat per tokens. |
| [packages](/ca/api/packages/) | Contractes principals i assistents de canalització (model, core, utils, plugin-kit, CLI). |
| [renderers](/ca/api/renderers/) | Integracions específiques del framework (React, Vue, Svelte, Storybook, i més). |
| [platforms](/ca/api/platforms/) | Sortides de plataforma generades (Swift, Compose, Flutter, Android, WordPress, etc.). |
