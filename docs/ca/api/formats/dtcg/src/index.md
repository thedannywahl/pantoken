# dtcg

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/dtcg` — els tokens d'Instructure com a document de W3C Design Tokens (DTCG).

L'exportació per defecte és l'arbre `rebrand` DTCG; cada tema està disponible pel nom. Utilitza [toDtcg](functions/toDtcg.md) per a convertir un IR arbitrari tu mateix.
