# tokens

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/tokens` — el token IR canònic resolt, venut com a JSON estàtic.

L'exportació per defecte és el tema `rebrand`; cada tema està disponible per nom i via
[byTheme](functions/byTheme.md). El JSON brut de Tokens Studio es troba a `@pantoken/tokens/raw`.
