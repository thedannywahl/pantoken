# Funció: applySpacing()

> **applySpacing**(`host`): `void`

Aplicar els atributs d'espaiat InstUI/CSS a `host` als estils en línia.

Les propietats gestionades es netegen primer, de manera que eliminar un atribut elimina el seu estil.

## Paràmetres

### host

`HTMLElement`

## Retorna

`void`
