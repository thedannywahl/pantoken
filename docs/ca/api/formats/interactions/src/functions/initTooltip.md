# Funció: initTooltip()

> **initTooltip**(`wrapper`, `tip`, `options?`): [`TooltipHandle`](../interfaces/TooltipHandle.md)

Connecta mostrar/amagar en flotació/focus amb retard a un embolcall de capina i la seva bombolla de punta. Retorna una funció de neteja per a ús en web component disconnectedCallback.

  CSS:  wrapper = element .instui-tooltip, tip = seu fill .tip
  WC:   wrapper = .instui-tooltip d'ombra, tip = .tip d'ombra

## Paràmetres

### wrapper

`HTMLElement`

### tip

`HTMLElement`

### options?

[`TooltipOptions`](../interfaces/TooltipOptions.md)

## Retorna

[`TooltipHandle`](../interfaces/TooltipHandle.md)
