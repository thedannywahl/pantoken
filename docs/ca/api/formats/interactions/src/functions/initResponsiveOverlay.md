# Funció: initResponsiveOverlay()

> **initResponsiveOverlay**(`host`, `onCommand`): `void`

Connecta comandos d'obrir/tancar més canvi de capa de superposició responsiu basat en amplada a un host: qualsevol panell lateral col·lapsible (per exemple, la safata d'un calaix) pot importar aquesta interacció en lloc que cada component la reimplementi.

## Paràmetres

### host

`HTMLElement`

### onCommand

[`OnCommand`](../type-aliases/OnCommand.md)

## Retorna

`void`
