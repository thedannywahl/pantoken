# Interfície: RemoveOptions

Opcions per a una eliminació basada en temps d'espera.

## Propietats

### timeout?

> `optional` **timeout?**: `number`

Mil·lisegons fins a la desestimació. Per defecte al `--timeout` calculat del destí.

***

### transition?

> `optional` **transition?**: `"fade"` \| `"none"`

Tractament de sortida. Per defecte a `"fade"`, coincidint amb InstUI Alert.
