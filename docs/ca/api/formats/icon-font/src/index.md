# icon-font

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/icon-font` — construir una font d'icones instal·lable d'Instructure (WOFF2 + TTF) amb una fulla d'estils coincident i mapa de punts de codi. A diferència dels camins SVG en línia, una font s'instal·la en un dispositiu, de manera que funciona en aplicacions de disseny i contextos sense connexió on l'eina web no és accessible.

Els glifos basats en traços (Lucide) es contornen per a emplenat de manera que es representin com a glifos de font reals; els glifos basats en emplenat (personalitzat d'Instructure) es passen.
