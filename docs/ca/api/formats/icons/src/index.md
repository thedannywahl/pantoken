# icons

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/icons` — una vista ergonòmica sobre els tokens `&lt;image&gt;` de l'IR.

Aquesta no és una segona font; filtra l'IR canònic de `@pantoken/tokens` als tokens d'icones i descodifica cada URI de dades de nou a SVG en línia, exposant una forma similar a `SimpleIconTokenData` que els consumidors de markdown/rehype ja utilitzen.
