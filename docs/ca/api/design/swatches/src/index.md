# swatches

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/swatches` — exportar colors d'Instructure com a paletes de mostres de dissenyador.

Les mostres són una reducció plana dels tokens a colors nomenats, entregades *directament a un dissenyador*
per importar a la seva eina. Això no és un format d'intercanvi (utilitza `@pantoken/dtcg` o
`@pantoken/figma` per a això) — és un fitxer de paleta final: Adobe ASE, GIMP `.gpl`, o Sketch
`.sketchpalette`.
