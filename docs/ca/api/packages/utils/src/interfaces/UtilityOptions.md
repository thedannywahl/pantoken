## Properties

### prefix?

> `optional` **prefix?**: `string` \| `null`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

El prefix de classe. Qualsevol cadena veritable estableix un namespace per a cada classe (`"instui"` → `.instui-bg-…`); qualsevol valor fals (`null`/`undefined`/`""`) elimina completament el prefix (`.bg-…`).
