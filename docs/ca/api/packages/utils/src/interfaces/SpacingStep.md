# Interface: SpacingStep

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Una entrada de l'escala d'espaiat pantoken: la clau curta, la clau llarga (paraula), i el valor CSS compartit.

## Properties

### short

> **short**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

La clau d'escala curta, p. ex. `"sm"` (la clau curta del pas zero és `"0"`).

---

### long

> **long**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

La clau llarga, escrita amb paraules, p. ex. `"small"` (la clau llarga del pas zero és `"none"`).

---

### value

> **value**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

El valor CSS — una referència de token, o un simple `"0"`/`"auto"`.
