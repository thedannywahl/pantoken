# cli

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/cli` — `pantoken generate <target>`.

Emetera font de token de disseny native i altres no-npm en un dipòsit consumidor — els objectius que no
encaixen el model de paquet npm. Compatibles ara: `swift` (amb un stub de manifest SPM `Package.swift`, de manera que
la publicació del registre és més tard un gir de configuració), `android`, `compose`, `flutter`, `wordpress`,
`vanilla`, `drupal`, `swatches`, `rust`, `icon-font`, `pendo`, `jekyll`, `hugo`, i `mintlify`.
