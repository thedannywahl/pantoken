# Interfície: IconEntry

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Una icona resolta, tal com la retorna un [IconResolver](../type-aliases/IconResolver.md).

## Propietats

### name

> **name**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

El nom / codi de la icona.

***

### svg?

> `optional` **svg?**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Marques SVG en línia, quan estigui disponible.

***

### path?

> `optional` **path?**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Dades de camí SVG, per a icones de marca de camí únic.

***

### viewBox?

> `optional` **viewBox?**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

El `viewBox` SVG (per defecte `"0 0 24 24"`).

***

### source?

> `optional` **source?**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

El proveïdor que va produir aquesta entrada.
