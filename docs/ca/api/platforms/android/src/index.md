# android

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/android` — emeteri els tokens de disseny d'Instructure com XML de recursos Android.

Aplaneix la IR a valors concrets de mode únic (`toStyleDictionary` de `@pantoken/core`), després emeteri `res/values/colors.xml` (tokens de color) i `res/values/dimens.xml` (tokens de dimensió) a través de `@pantoken/sd-config`. Style Dictionary aplica les transformacions d'Android (`#aarrggbb`, `dp`/`sp`).
