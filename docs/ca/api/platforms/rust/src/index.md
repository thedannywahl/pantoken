# rust

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/rust` — emetre tokens de disseny de l'Instructure com a constants de Rust per a les dues GUIs natives de Rust principals: **egui** (`Color32`) i **iced** (`Color`). Els colors es converteixen en el tipus de color del framework; les dimensions es converteixen en `f32` (px). Els UIs de Rust renderitzats per web (Tauri, Dioxus-web, Leptos, Yew) haurien de
utilitzar `@pantoken/css` en lloc seu.
