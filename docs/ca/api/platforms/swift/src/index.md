# swift

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/swift` — emetre tokens de disseny de l'Instructure com Swift via Style Dictionary.

Aquesta és la prova native de pantoken: aplatana l'IR a valors concrets de mode únic
(`@pantoken/core`'s `toStyleDictionary`), mantén els tokens natiu-tipats (colors, dimensions,
números), i els lliura a `@pantoken/sd-config`. Canviar `platform` a `flutter`/`compose`
reutilitza el mateix camí.
