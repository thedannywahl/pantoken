# email

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/email` — tokens de disseny d'Instructure per a correu HTML.

Els clients de correu no admeten propietats CSS personalitzades i sovint eliminen `&lt;style&gt;`, de manera que els tokens es resolen completament
a valors concrets per a estil integrat. Els colors són hexadecimals; les dimensions mantenen les seves unitats `px`.
Els iconos s'exclouen. Els mapes `light`/`dark` es claven pel nom del token camelCased.
