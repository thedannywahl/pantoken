# wordpress

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/wordpress` — tokens de disseny Instructure com a `theme.json` de tema de blocs WordPress.

[toThemeJson](functions/toThemeJson.md) converteix qualsevol IR; [themeJson](variables/themeJson.md) és el document `rebrand` preparat. El CLI pot escriure'l en un directori de tema: `pantoken generate wordpress --out ./my-theme`.
