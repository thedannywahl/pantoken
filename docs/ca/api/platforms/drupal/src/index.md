# drupal

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/drupal` — emet un subtema de Drupal amb tema d'Instructure.

Produeix l'estil de token (des de `@pantoken/css`) i un estil de prosa amb aspecte InstUI (des de
`@pantoken/components`, estilitzant el contingut en una regió `.pantoken-prose`), més el `*.info.yml`
i `*.libraries.yml` que necessita un tema de Drupal 10/11 per carregar-los. Deixa els fitxers a
`themes/custom/&lt;machine&gt;/`.
