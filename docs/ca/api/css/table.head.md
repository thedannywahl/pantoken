# CSS: table.head

`thead` — El grup de fila de capçalera de la taula (InstUI `Table.Head`).

El modificador `-layout-stacked` del pare `table` amaga visualment aquest membre (els seus títols de columna apareixen per cel·la en comptes de això) — consulta la documentació pròpia de `table` per a aquest modificador.

## Ús

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.head.css";
```

## Tokens consumits

| Token | Tipus | Valor |
| --- | --- | --- |
| `--instui-component-table-head-background` | `<color>` | `light-dark(#ffffff, #10141A)` |
