# CSS API reference

La referència de l'API CSS cobreix la capa de components basada en classes de pantoken: components, utilitats, regles globals i declaracions construïdes sobre el sistema de tokens.

| [maskglobal](/ca/api/css/maskglobal.md)                       | `.--mask-overlay`                              | Una còpia doble global dels modificadors de superposició del component `mask` — `--mask-overlay`, `--mask-fullscreen`, `--mask-blur` — usable nua o encadenada a qualsevol component, sense embolicar en un element `.instui-mask`.                                                                                                                                                                                                                                               |

| [responsive](/ca/api/css/responsive.md)                       | `[class*="-hidden-"],[class*="-show-"]`        | Classes de mostra/amaga d'amplada de finestra o contenidor a través d'una escala de punts de ruptura temàtica.                                                                                                                                                                                                                                                                                                                                                                    |

## Rules

| Name                          | Class          | Summary                                                                                                                                                                                                                                                                                          |
| ----------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [base](/ca/api/css/base.md)   | `*`            | La reinicialització global opcional: `box-sizing`, la superfície de la pàgina, color de text base i tipus de lletra, `color-scheme`, i valors per defecte de l'enllaç.                                                                                                                           |
| [prose](/ca/api/css/prose.md) | `:where(body)` | Valors tipogràfics per defecte per a HTML brut — encapçalaments, paràgrafs, llistes, enllaços i codi — aplicats automàticament on sigui importat (valor per defecte `:where(body)`); passa `options.scope` per a dirigir-se a una arrel de contingut diferent en lloc d'això (p. ex. `.vp-doc`). |
