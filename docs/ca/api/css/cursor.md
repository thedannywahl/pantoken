# CSS: cursor

`.--cursor-pointer` — `cursor` com una classe composable i global — `.--cursor-&lt;value&gt;` — usable com a sola o encadenada a qualsevol component (`.instui-button.--cursor-pointer`).

**Font:** [index.ts](https://github.com/thedannywahl/pantoken/blob/main/formats/components/src/utilities/cursor/index.ts)

## Ús

```css
@import "@pantoken/components/utilities.css";
```

## Exemples

```html
<div class="--cursor-pointer">…</div>
```

## Modificadors

| Modificador | Descripció |
| --- | --- |
| `.--cursor-auto` | cursor: auto. |
| `.--cursor-default` | cursor: default. |
| `.--cursor-grab` | cursor: grab. |
| `.--cursor-move` | cursor: move. |
| `.--cursor-not-allowed` | cursor: not-allowed. |
| `.--cursor-pointer` | cursor: pointer. |
| `.--cursor-text` | cursor: text. |
| `.--cursor-wait` | cursor: wait. |
