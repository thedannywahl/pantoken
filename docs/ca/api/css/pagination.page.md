# CSS: pagination.page

`.page` — Un enllaç o botó de pàgina (InstUI `Pagination.Page`); la pàgina actual porta `[aria-current]`.

## Ús

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/pagination.page.css";
```

## Modificadors

| Modificador | Descripció |
| --- | --- |
| `.-current` | La pàgina actual; el mateix estil que `[aria-current]`. |
