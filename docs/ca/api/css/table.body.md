# CSS: table.body

`tbody` — El grup de fila de dades de la taula (InstUI `Table.Body`).

El modificador `-layout-stacked` del pare `table` reformata aquest membre — consulta la documentació pròpia de `table` per a aquest modificador.

## Usage

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.body.css";
```
