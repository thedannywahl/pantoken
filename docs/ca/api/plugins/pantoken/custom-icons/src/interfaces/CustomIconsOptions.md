# Interfície: CustomIconsOptions

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Opcions per al connector [customIcons](../functions/customIcons.md).

## Propietats

### names?

> `optional` **names?**: `string`[]

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Noms d'icones per emetreLet com a tokens `&lt;image&gt;` (per defecte: totes les icones de tercers).

***

### prefix?

> `optional` **prefix?**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

El prefix del nom del token (per defecte: `--instui-icon-`, que coincideix amb l'espai de noms de la icona InstUI).
