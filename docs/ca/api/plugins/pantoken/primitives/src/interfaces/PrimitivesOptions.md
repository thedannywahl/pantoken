# Interfície: PrimitivesOptions

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Opcions per a [primitivesCss](../functions/primitivesCss.md).

## Propietats

### prefix?

> `optional` **prefix?**: `string` \| `null`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

El prefix de classe. Una cadena veritable namespacea cada classe (`"instui"` → `.instui-bg-…`); qualsevol valor falsy cau el prefix completament (`.bg-…`). El `primitives.css` expedit es construeix amb `"instui"`.
