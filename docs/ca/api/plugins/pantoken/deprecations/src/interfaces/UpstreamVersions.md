# Interfície: UpstreamVersions

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

La versió actual resolta de cada nivell amunt (des de la procedència `@pantoken/tokens`).

## Propietats

### ui

> **ui**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Versió resolta `@instructure/ui-*`, per exemple `"11.7.4"`.

***

### designTokens

> **designTokens**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Referència fixada `@instructure/instructure-design-tokens`, per exemple `"v1.5.0"`.
