# Interfície: VisualDebugOptions

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Opcions del connector [visualDebug](../functions/visualDebug.md).

## Propietats

### color?

> `optional` **color?**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

El color de contorn de depuració (per defecte: magenta brillant a través de `--pantoken-visual-debug-color`).

***

### position?

> `optional` **position?**: `"append"` \| `"prepend"`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

On les regles es col·loquen relatives a la fulla d'estils: `"append"` (per defecte) o `"prepend"`.
