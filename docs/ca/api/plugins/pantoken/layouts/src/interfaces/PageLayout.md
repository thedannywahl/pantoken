# Interfície: PageLayout

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Un disseny de pàgina inicial: una composició senzilla de components existents, cap selector CSS nou.

## Propietats

### name

> **name**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Id estable, coincideix amb el nom de fitxer font (per exemple `"hero"`).

***

### title

> **title**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Etiqueta mostrada en un selector de disseny.

***

### html

> **html**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

HTML brut per al disseny, construït a partir de classes `@pantoken/components`.
