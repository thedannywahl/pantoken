# simple-icons

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/plugin-simple-icons` — porta els glifos de marca Simple Icons a pantoken.

El connector defineix un ganxo `tokens` (emet glifos de marca seleccionats com a tokens `&lt;image&gt;`, de manera que flueixen a CSS i natiu també) _i_ un ganxo `rehype` (resol codis `:brand:` en renderitzar). El mateix connector, qualsevol capa — la forma generalitzada de la fàbrica d'icones `mcp-stack/portal`.
