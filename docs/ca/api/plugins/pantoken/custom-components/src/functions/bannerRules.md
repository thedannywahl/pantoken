# Funció: bannerRules()

> **bannerRules**(`prefix?`): `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Construeix el CSS de disposició de bàner (comentari de doc + regles), substituint `prefix` per la sentinella `pfx-`.
Per defecte `"instui-"` per a la fulla d'estils enviada; passeu `""` per a una construcció sense prefix.

## Paràmetres

### prefix?

`string` = `"instui-"`

## Retorna

`string`
