Restabliment base

Aquest resultat es renderitza amb base.css carregat primer. La superfície de la pàgina, el color del text base i la font, i box-sizing provenen tots dels tokens — no cal cap regla pròpia.

Els elements bàsics prenen valors per defecte raonables, com ara aquest enllaç base, i tot se situa sobre la superfície de pàgina del token. Canvieu el tema (o clar/fosc) i la superfície, el text i l'enllaç el segueixen.
