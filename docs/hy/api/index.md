# API حوالագիր

Pantoken API տեղեկատուն ընդգրկում է հիմնական գրադարակներ, ձևաչափի արտանետողներ, պլատֆորմայի թիրախներ, պատկերիչներ, փաթեթավորիչի բրոշներ և դիզայն գործիքներ։

## Սկսեք այստեղ

| Տիրույթ | Նկարագիր |
| --- | --- |
| [CSS API reference](/hy/api/css/) | Բաղադրիչի դասեր, օգտեհատկներ, կանոններ, հայտարարություններ և token-ով հաստատված CSS վարքագիծ։ |
| [packages](/hy/api/packages/) | Հիմնական պայմանագրեր և խողովակի օգնականներ (model, core, utils, plugin-kit, CLI)։ |
| [renderers](/hy/api/renderers/) | Ֆրեյմվորկ-հատուկ ինտեգրացիաներ (React, Vue, Svelte, Storybook և ավելին)։ |
| [platforms](/hy/api/platforms/) | Գեներացված պլատֆորմայի ելքերը (Swift, Compose, Flutter, Android, WordPress և այլն)։ |

## Խմբերով դիտել

| Խումբ | Նկարագիր |
| --- | --- |
| [ai](/hy/api/ai/) | Գործակալի ակտիվներ և AI գործիքների փաթեթներ։ |
| [bundlers](/hy/api/bundlers/) | Փաթեթավորիչի ինտեգրացիաներ Next, Vite, Webpack, Tailwind, Panda և PostCSS-ի համար։ |
| [design](/hy/api/design/) | Դիզայն-մակերեսի ելքերը՝ Figma և վճռեր։ |
| [formats](/hy/api/formats/) | Ներմուծվող token/icon ձևաչափի ելքերը (CSS, SCSS, tokens, icons և ավելին)։ |
| [packages](/hy/api/packages/) | Հիմնական փաթեթի API-ներ, որոնք աշխատացնում են փոխակերպման խողովակը։ |
| [platforms](/hy/api/platforms/) | Գեներացված թիրախային էկոհամակարգեր և runtime-հատուկ արտահանումներ։ |
| [plugins](/hy/api/plugins/) | Pantoken, Vite, PostCSS և TypeDoc բրոշի API-ներ։ |
| [renderers](/hy/api/renderers/) | Ֆրեյմվորկ և docs-site պատկերիչներ և հարմարիչներ։ |
| [tools](/hy/api/tools/) | Ներքին գործիքների API-ներ, որոնք օգտագործվում են գեներացման և docs խողովակներով։ |
