# swatches

<span class="instui-pill -color-danger pantoken-doc-tag">Փորձարկումային</span>

`@pantoken/swatches` — արտահանեք Instructure գույները որպես դիզայների նմուշային պալետրա։

Նմուշները տոկենների հարթ կրճատում են անվանված գույների, որոնք հանձնվում են *ուղղակիորեն դիզայներին*
դրանք իրենց գործիքի մեջ ներմուծելու համար։ Սա փոխանակման ձևաչափ չէ (դրա համար օգտագործեք `@pantoken/dtcg` կամ
`@pantoken/figma`) — դա տերմինալային պալետրայի ֆայլ է՝ Adobe ASE, GIMP `.gpl`, կամ Sketch
`.sketchpalette`։
