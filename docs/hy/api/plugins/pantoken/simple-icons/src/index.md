# simple-icons

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/plugin-simple-icons` — բերել Simple Icons ապրանքային գլիֆները pantoken-ի մեջ:

Պլագինը սահմանում է `tokens` կեռ (արտանետել ընտրված ապրանքային գլիֆները որպես `&lt;image&gt;` տոկեններ, որպեսզի նրանք հոսեն
CSS-ի և հայրենական հետ) _և_ `rehype` կեռ (լուծել `:brand:` կոդերը հայտնի ժամանակ): Նույն պլագինը,
կամ շերտ — `mcp-stack/portal` պատկերային գործարանի ընդհանրացված ձևը:
