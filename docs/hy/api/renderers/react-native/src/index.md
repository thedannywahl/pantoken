# react-native

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/react-native` — Instructure դիզայն մեջբերում-ներ որպես React Native `StyleSheet`-friendly
օբյեկտներ։ React Native-ն CSS փոփոխականներ չունի, ուստի մեջբերում-ներ լրիվ լուծված են կոնկրետ արժեքների հանդեպ:
գույներ մնում են hex տողեր, չափումներ դառնում են թվեր (dp), և պատկերակներ բացառված են։
