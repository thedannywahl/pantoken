# docusaurus

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/docusaurus` — Instructure տոկենների հետ Docusaurus կայքային թեմա:

Docusaurus ոճներ գալիս են Infima-ից, որի թեմայական `--ifm-*` CSS փոփոխականներով է առաջնորդվում: Սա ցույց տալ `var(--instui-*)`-ին, այնպես որ արձակել արդյունքը `src/css/custom.css`-ի մեջ (մեջ `@pantoken/css`-ի, որն սահմանում է custom հատկությունները) վերասկինել փաստաթղթերը Instructure տեսքով, մինչդեռ լույս/մութ շարունակում է հոսել նույն տոկենների միջոցով:
