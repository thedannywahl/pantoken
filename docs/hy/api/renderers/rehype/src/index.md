# rehype

<span class="instui-pill -color-danger pantoken-doc-tag">Փորձարկումային</span>

`@pantoken/rehype` — render `:icon:` կոդեր որպես ներգծային SVG։

Plugin-ը քայլում է hast տեքստի հանգույցների միջով և փոխարինում է `:code:` մեջբերում-ներ ներգծային SVG տարրով,
լուծելով յուրաքանչյուր կոդ շղթայի միջոցով՝ plugin `rehype` resolver-ներ նախ, ապա ցանկացած հստակ
`resolve`, այնուհետ ներկառուցված `@pantoken/icons` հավաքածուն։ Այն փոխանցում է `rehype-instui-markdown` վրա
բաժանված պատկերակ դրույսը։
