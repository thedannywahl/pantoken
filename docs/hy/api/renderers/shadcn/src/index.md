# shadcn

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/shadcn` — theme shadcn/ui Instructure մեջբերում-ներով։

[toShadcnCss](functions/toShadcnCss.md)-ը արտանետում է `:root` բլոկ, որը shadcn-ի CSS փոփոխականները ուղղել է `var(--instui-*)`-ին։
Հատկացրեք այն `@pantoken/css`-ի կողքին (որը սահմանում է հատուկ հատկությունները), և shadcn բաղադրիչները
ստանում են Instructure տեսքը: Պատկերները ինքնաբերաբար հավասարեցվում են — shadcn-ն և Instructure-ը երկուսն էլ օգտագործում են Lucide:
