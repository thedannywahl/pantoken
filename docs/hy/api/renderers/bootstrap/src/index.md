# bootstrap

<span class="instui-pill -color-danger pantoken-doc-tag">Փորձարկումային</span>

`@pantoken/bootstrap` — Instructure տոկենների հետ Bootstrap 5 թեմա:

Bootstrap-ի `--bs-*` CSS փոփոխականները ցույց տալ `var(--instui-*)`-ին: Գցեք այն մեջ `@pantoken/css`-ի հետ և Bootstrap բաղադրիչները ընդունում են Instructure տեսք, մինչդեռ թեմայի փոփոխում շարունակում է հոսել նույն custom հատկությունների միջոցով:
