# Function: injectContentStylesheet()

> **injectContentStylesheet**(`editor`, `url`): `void`

Ավելացնում է `<link rel="stylesheet">` խմբագրի բովանդակ փաստաթղթին `&lt;head&gt;` գործարկման ժամանակ:
Idempotent մեկ URL-ի համար — այս կանչը երկու անգամ միևնույն `url`-ով երկրորդ անգամ գործողություն չ:

## Parameters

### editor

`Editor`

### url

`string`

## Returns

`void`
