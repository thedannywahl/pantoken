# react-markdown

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/react-markdown` — Markdown-ը render անել Instructure UI բաղադրիչներով և pantoken պատկերակներով։

Լռելյալ գրառումը render անում է GitHub-Flavored Markdown, ներգծային `:icon:` մեջբերում (via
`@pantoken/rehype` + `@pantoken/icons`), գույն-կոդ նմուշներ, և GitHub-style ահազանգներ։ MDX
մատակարարը գտնվում է `@pantoken/react-markdown/mdx`-ում։
