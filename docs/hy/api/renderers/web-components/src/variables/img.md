# Փոփոխական: img

> `const` **img**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Ալֆա</span>

`&lt;instui-img&gt;` — տոկեն-ոճավորված `&lt;img&gt;`՝ կառուցված `src`/`alt`-ից։ `constrain`-ը քարտեզում է
`-constrain-&lt;value&gt;`-ին (օրինակ. `cover`, `contain`) և `display="block"`-ը `-display-block`-ին։

## Օրինակ

```html
<instui-img src="/hero.jpg" alt="Campus" constrain="cover" display="block"></instui-img>
```
