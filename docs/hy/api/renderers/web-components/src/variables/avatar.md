# Variable: avatar

> `const` **avatar**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-avatar&gt;` — շրջանաձև (կամ ուղղանկյուն) ավատար: `variant` քարտեզ է անում `-color-&lt;variant&gt;`-ի, `size`-ից `-size-&lt;size&gt;`, և `shape="rectangle"`-ից `-shape-rectangle`-ի; տեղադրված բովանդակությունը նախաբաններն են, կամ `&lt;img&gt;` (օգտագործել բացարձակ/CDN `src`) լուսանկար ցուցադրելու համար:

## Example

```html
<instui-avatar size="lg" margin="small">JS</instui-avatar>
<instui-avatar shape="rectangle" variant="green" margin="small">AB</instui-avatar>
```
