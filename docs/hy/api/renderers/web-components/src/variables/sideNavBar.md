# Փոփոխական: sideNavBar

> `const` **sideNavBar**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Ալֆա</span>

`&lt;instui-side-nav-bar&gt;` — ուղղահայաց նավիգացիայի ռելսի կերտված թաղտ: `minimized="true"` ավելացնում է
`-minimized` մոդիֆայերը (փակած ռելս); սպառողը տեղավորում է նավ իրեր:

## Օրինակ

```html
<instui-side-nav-bar>
  <a href="/dashboard">Dashboard</a>
  <a href="/courses">Courses</a>
</instui-side-nav-bar>
```
