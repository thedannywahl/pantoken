# Փոփոխական: metric

> `const` **metric**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Ալֆա</span>

`&lt;instui-metric&gt;` — պիտակավորված վիճակագրություն. մեծ `value` փոքր `label`-ի վրա։ Երկուսն էլ գալիս են
հատկանիշներից (հատկացված), ոչ թե slot-ներից։

## Օրինակ

```html
<instui-metric value="1,024" label="Enrolled"></instui-metric>
```
