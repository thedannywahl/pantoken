# Փոփոխական: rating

> `const` **rating**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Ալֆա</span>

`&lt;instui-rating&gt;` — աստղերի վարկանիշ `role="img"`-ի հետ: `value` լցված աստղերի թիվն է, `max`
ընդամենը (լռելյալ 5), և `label` վերականգնում է մատչելի անունը (լռելյայն `value/max`): Աստղերը
արտացոլվում են որպես ընդլայն SVG գլիֆեր (պինդ = լցված), չափափ տեքստին:

## Օրինակ

```html
<instui-rating value="4" max="5" label="4 out of 5 stars"></instui-rating>
```
