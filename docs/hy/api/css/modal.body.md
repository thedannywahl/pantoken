# CSS: modal.body

`.body` — Բովանդակության շրջան (InstUI `Modal.Body`); միայն `&lt;img&gt;` ամբողջ կրծքով գնում:

Հայր `modal`'s `-overflow-fit`, `-density-compact`, և `-color-inverse` փոփոխիչներ վերականգնում են այս անդամին — տե՛ս `modal`'s սեփական doc այդ փոփոխիչների համար:

## Օգտագործում

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/modal.body.css";
```
