# CSS: modal.header

`.header` — Վերնագրի շարք (InstUI `Modal.Header`):

Հայր `modal`'s `-density-compact` և `-color-inverse` փոփոխիչներ վերականգնում են այս անդամին — տե՛ս `modal`'s սեփական doc այդ փոփոխիչների համար:

## Օգտագործում

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/modal.header.css";
```
