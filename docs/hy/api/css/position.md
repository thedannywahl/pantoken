# CSS: position

`.--position-relative` — `position` որպես կազմվող, հանրամատչելի դասի — `.--position-&lt;value&gt;` — գործածական մերկ կամ շղթայված ցանկացած բաղադրիչում (`.instui-button.--position-relative`):

**Աղբյուր:** [index.ts](https://github.com/thedannywahl/pantoken/blob/main/formats/components/src/utilities/position/index.ts)

## Օգտագործում

```css
@import "@pantoken/components/utilities.css";
```

## Օրինակներ

```html
<div class="--position-relative">…</div>
```

## Մոդիֆիկատորներ

| Մոդիֆիկատոր | Նկարագիր |
| --- | --- |
| `.--position-absolute` | position: բացարձակ: |
| `.--position-fixed` | position: ֆիքսված: |
| `.--position-relative` | position: հարաբերական: |
| `.--position-static` | position: ստատիկ: |
| `.--position-sticky` | position: սոսինկ: |
