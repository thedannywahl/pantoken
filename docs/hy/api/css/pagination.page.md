# CSS: pagination.page

`.page` — էջի հղում կամ կոճակ (InstUI `Pagination.Page`); ընթացիկ էջը փոխանցում է `[aria-current]`:

## Օգտագործում

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/pagination.page.css";
```

## Մոդիֆիկատորներ

| Մոդիֆիկատոր | Նկարագիր |
| --- | --- |
| `.-current` | Ընթացիկ էջ; նույն ոճավորումը որպես `[aria-current]`: |

## Փոփոխական վիճակներ

| Վիճակ | Նկարագիր |
| --- | --- |
| `:state(current)` | — |
