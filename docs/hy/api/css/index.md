# CSS API حوالագիր

CSS API հղումը ընդգրկում է pantoken-ի դասի վրա հիմնված բաղադրիչի շերտը. բաղադրիչներ, utility-ներ, գլոբալ կանոններ և թոքեն համակարգի վրա կառուցված հայտարարություններ:
