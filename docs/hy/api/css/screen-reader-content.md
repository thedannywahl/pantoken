# CSS: screen-reader-content

`.instui-screen-reader-content` — Տեսականորեն թաքցնում է բովանդակությունը, մինչ այն մատչելի պահում է օժանդակ տեխնոլոգիաներին (ստանդարտ կտրման մեթոդ):

**Աղբյուր:** [screen-reader-content.css](https://github.com/thedannywahl/pantoken/blob/main/formats/components/src/utilities/screen-reader-content/screen-reader-content.css)

## Մուտքականություն

Պահպանում է տեքստը հասանելիության ծառում էկրան ընթերցողների համար, մինչ այն հեռացնում է տեսական դասավորությունից:

## Օգտագործում

```css
@import "@pantoken/components/components.css";
```

## Օրինակներ

```html
<a class="instui-link" href="#examples" target="_blank">example</a>
<span class="instui-screen-reader-content">Opens in a new window</span>
```
