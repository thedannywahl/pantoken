# CSS: hero

`div[class~="instui-hero"]` — Լայն լայնության վերնագրի բաժին վերնագրով, ենթավերնագրով և ընտրովի ֆոնային պատկերով:

✅ Օգտագործեք Hero-ն երբ:

- Ձեզ անհրաժեշտ է ընդգծված էջի վերնագիր տեսային հիերարխիայով
- Էջը շահում է խոշոր, աչքի ընկնող բացվածքային բաժինից
- Ցանկանում եք ներառել ֆոնային պատկերներ կամ գրադիենտ շեշտեր
  🚫 Մի օգտագործեք Hero-ն երբ:

- Պարզ էջի վերնագիր կառուցել — փոխարենը օգտագործեք Page-Layout-ը
- Հերոսը մրցում է կրիտիկական բովանդակության հետ — հատուկ ուշադրություն դարձրեք ընթերցելիությանը

## Accessibility

- Համոզվեք, որ վերնագիրը `&lt;h1&gt;` պիտակում է իմաստային կառուցվածքի համար
- Եթե օգտագործում եք ֆոնային պատկերներ, տրամադրեք բավարար գույնի հակադրություն տեքստի համար
- Խուսափեք տեսանյութի կամ անիմացիայի ինքնաբացումից, որը կարող է շեղել բովանդակությունից

## Usage

```css
@import "@pantoken/plugin-layouts/layouts.css";
```

## Slots

| Slot       | Description                       |
| ---------- | --------------------------------- |
| `subtitle` | Հերո ենթավերնագիր բովանդակություն |
| `title`    | Հերո վերնագիր բովանդակություն     |

## Parts

| Part                 | Description                                      |
| -------------------- | ------------------------------------------------ |
| `.instui-actions`    | Ընտրովի գործողության կոճակներ կամ հղումներ:      |
| `.instui-background` | Ընտրովի ֆոնային շերտ (պատկեր կամ գրադիենտ):      |
| `.instui-content`    | Հերո տեքստի և գործողությունների համար կոնտեյներ: |
| `.instui-overlay`    | Ընտրովի կիսաթափ ծածկ տեքստի հակադրության համար:  |
| `.instui-subtitle`   | Ընտրովի օժանդակ տեքստ կամ նկարագրություն:        |
| `.instui-title`      | Հերո հիմնական վերնագիր (սովորաբար `&lt;h1&gt;`): |
