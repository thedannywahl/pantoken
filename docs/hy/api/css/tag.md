# CSS: tag

`.instui-tag` — Ներամեջ չիպ հատուկ բառի կամ ֆիլտրի համար:

Սահմանում է իր սեփական հորիզոնական `padding` (`-size-sm`/`-size-lg` մասշտաբեն այն); շղթայելով `-p-*`/`-padding-*` տարածության ծայրամեջ փոփոխիչը փոխարինում է այդ ներառված արժեքը:

**Աղբյուր:** [tag.css](https://github.com/thedannywahl/pantoken/blob/main/formats/components/src/components/tag/tag.css)

## Usage

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/tag.css";
```

## Demo

```demo
self:tag
```

## Examples

```html
<span class="instui-tag -size-sm">small</span>
```

## Modifiers

| Modifier       | Description                                                        |
| -------------- | ------------------------------------------------------------------ |
| `.-inline`     | Կարդում է տեքստի հետ ներամեջ և ստանում է հետևյալ հեռացրածի սիմվոլ: |
| `.-readonly`   | Միայն կարդալ (ոչ հեռացվող) պիտակ:                                  |
| `.-size-large` | Մեծ պիտակ: Երկար ձևի այլ անուն `-size-lg`-ի:                       |
| `.-size-lg`    | Մեծ պիտակ:                                                         |
| `.-size-sm`    | Փոքր պիտակ:                                                        |
| `.-size-small` | Փոքր պիտակ: Երկար ձևի այլ անուն `-size-sm`-ի:                      |

## Pseudo-elements

| Pseudo-element | Description                                                      |
| -------------- | ---------------------------------------------------------------- |
| `::after`      | Կերտում է հետևյալ հեռացրածի սիմվոլը հեռացվող ներամեջ պիտակի վրա: |
