# CSS: table.head

`thead` — Աղյուսակի գլխավոր շարքի խումբ (InstUI `Table.Head`):

Ծնողական `table`-ի `-layout-stacked` փոփոխիչը տեսողականորեն թաքցնում է այս անդամին (դրա սյունակի վերնագրերը հայտնվում են յուրաքանչյուր բջջի համար) — տե՛ս `table`-ի սեփական փ documentation-ը այդ փոփոխիչի համար:

## Usage

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.head.css";
```

## Tokens consumed

| Token                                      | Type      | Value                          |
| ------------------------------------------ | --------- | ------------------------------ |
| `--instui-component-table-head-background` | `<color>` | `light-dark(#ffffff, #10141A)` |
