# CSS: table.row

`tr` — Աղյուսակի շարք (InstUI `Table.Row`):

Ծնողական `table`-ի `-hover` և `-layout-stacked` փոփոխիչները վերափոխում են այս անդամին — տե՛ս `table`-ի սեփական փ documentation-ը այդ փոփոխիչների համար:

## Օգտագործում

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.row.css";
```
