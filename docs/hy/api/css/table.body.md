# CSS: table.body

`tbody` — Ամսի նստատեղ շարք խմբել (InstUI `Table.Body`):

Ծնողական `table`-ի `-layout-stacked` փոփոխիչը վերափոխում է այս անդամին — տե՛ս `table`-ի սեփական փ documentation-ը այդ փոփոխիչի համար:

## Usage

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.body.css";
```
