# CSS: two-column

`div[class~="instui-two-column"]` — Երկու սյունակ դասավորություն ձախ և աջ բովանդակության ոլորտներով:

✅ Օգտագործել երկու սյունակ երբ:

- Ունեք երկու բովանդակության ոլորտ մոտավորապես հավասար կարևորության
- Համեմատում կամ հակասկում դրանց երկու բովանդակության հավաքածուներ կողք-կողքի
- Կառուցել արձագանքական դասավորություն, որը վերահորդացում է բջջային
  🚫 Մի օգտագործեք երկու սյունակ երբ:

- Մեկ սյունակ իշխում է էջի վրա — օգտագործեք ասիմետրիկ դասավորություն փոխարենը
- Բովանդակությունը չի շահում կողք-կողքի ներկայացումից

## Accessibility

- Վստահացեք, որ երկու սյունակներն ընկալելի և օգտագործելի են նեղ տեսադաշտերում
- Օգտագործել իմաստային ուղենիշներ (օր. `&lt;section&gt;`) սյունակի բովանդակությունը փաթաթելու համար
- Պահել բավարար տեղ և հակադրություն սյունակների միջև

## Usage

```css
@import "@pantoken/plugin-layouts/layouts.css";
```

| Part              | Description                                   |

| `.instui-left`    | Ձախ սյունակի բովանդակության ոլորտ:            |
| `.instui-right`   | Աջ սյունակի բովանդակության ոլորտ:             |
