# tokens

<span class="instui-pill -color-warning pantoken-doc-tag">Բետա</span>

`@pantoken/tokens` — կանոնական լուծված token IR, վաճառվում է որպես ստատիկ JSON։

Կանխադրված արտահանումը `rebrand` թեման է; յուրաքանչյուր թեմա հասանելի է անունով և [byTheme](functions/byTheme.md)-ի միջոցով։ Հում Tokens Studio JSON գտնվում է `@pantoken/tokens/raw`-ում։
