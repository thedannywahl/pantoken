# icon-font

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/icon-font` — ստեղծել տեղադրելի Instructure պատկերակային շրիֆտ (WOFF2 + TTF) հետ համապատասխան
ոճավորման թերթ և կոդային կետերի քարտեզ: Ի տարբերություն inline-SVG ուղիների, շրիֆտը տեղադրվում է սարքի վրա, ուստի այն
աշխատում է դիզայնի ծրագրերում և անցանց համատեքստերում, որտեղ վեբի գործիքները հասանելի չեն:

Հարվածի վրա հիմնված գլիֆերը (Lucide) ուրվագծված են լրացումներով, որպեսզի դրանք անցեն իսկական շրիֆտային գլիֆերի տեսքով; լրացում-հիմնված
գլիֆերը (Instructure custom) անցնում են:
