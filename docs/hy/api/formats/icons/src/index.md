# icons

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/icons` — արգոնոմիկ տեսք IR-ի `&lt;image&gt;` տոկենների վրա:

Սա երկրորդ աղբյուր չէ; այն ֆիլտրում է կանոնական IR-ը `@pantoken/tokens`-ից պատկերակային
տոկենների և վերծանում է յուրաքանչյուր data-URI-ն հետ inline SVG-ի, բացահայտելով ձև, որը մոտ է
`SimpleIconTokenData` մակբառ/rehype սպառողների կողմից արդեն օգտագործվածին:
