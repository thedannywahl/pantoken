# Function: initTooltip()

> **initTooltip**(`wrapper`, `tip`, `options?`): [`TooltipHandle`](../interfaces/TooltipHandle.md)

Մալուխ հավիզ/ֆոկուս ցույց-թաքցնել հապաղման հետ շարակցվածքի թաղամ և դրա խորհրդավոր
փուչ: Վերադարձնում է մաքրման ֆունկցիա վեբ բաղադրիչի disconnectedCallback-ում օգտագործման համար:

CSS: wrapper = .instui-tooltip տարր, tip = դրա .tip երեխա
WC: wrapper = shadow .instui-tooltip, tip = shadow .tip

`HTMLElement`

### tip

`HTMLElement`
