# Ֆունկցիա: initProgressCircle()

> **initProgressCircle**(`target`, `options?`): [`ProgressCircleHandle`](../interfaces/ProgressCircleHandle.md)

Ազատել ProgressCircle-ի մատցում-անիմացիա փոփոխիչը դրա կազմաձևված հետաձգումից հետո:

Հապաղումը բացահայտ միլիվայրկյանային տարբերակ է կամ թիրախի հաշվարկված, միավորից զուրկ
`--animation-delay` հատկություն: Բացակայող, բացասական և ոչ վերջավոր արժեքները դառնում են զրո: Ե՛ւ կանոնական փոփոխիչը և դրա հանդուրժյալ տառասխալ կեղծանունը ընդունվում և հեռացվում են:
