# Ֆունկցիա: baseCss()

> **baseCss**(): `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Բետա</span>

Կառուցեք ընտրովի բազային/վերականգնիչ ոճ-հաղորդակցման թերթ՝ տոկենից ստացված գլոբալ փաստաթղթի կանխակարգեր (box-sizing, body վերականգնում, էջի մակերեսություն, բազային տեքստի գույն/տառատեսակ, `color-scheme`, բազային հղում), որին հաջորդում է focus-ring կանոնները (փաստաթղթի մակարդակի կանխակարգ, որը ուղղված է մերկ կենտրոնացրածներին)։ Միայն ring *կանոնները* ապրում են այստեղ — այն `--instui-focus-outline-*` հատուկ հատկությունները, որոնք նրանք կարդում են, գալիս են տոկեն թերթում (`@pantoken/css`), ուստի `base.css` այլեւ չի վերասահմանում դրանք։ Բեռնեք այն մեկ անգամ, բաղադրիչ և տեքստային թերթերից առաջ, երբ pantoken-ը սեփական է էջը։

## Վերադարձվող արժեք

`string`
