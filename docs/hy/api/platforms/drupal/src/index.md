# drupal

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/drupal` — թողարկել Instructure-ի թեմայով Drupal ենթաթեմա

Արտադրում է token stylesheet (from `@pantoken/css`) և InstUI-look prose stylesheet (from `@pantoken/components`, styling content in a `.pantoken-prose` region), ինչպես նաև `*.info.yml` և `*.libraries.yml`, որոնք Drupal 10/11 թեմային անհրաժեշտ է դրանք բեռնելու համար: Քաշեք ֆայլերը `themes/custom/&lt;machine&gt;/` ֆոլդերում:
