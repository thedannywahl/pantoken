# swift

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/swift` — արտանետել Instructure դիզայն թոկենները որպես Swift Style Dictionary-ի միջոցով:

Սա pantoken-ի բնիկ ապացույց է. այն հարթեցնում է IR-ը կոնկրետ, մեկ-ռեժիմային արժեքների (`@pantoken/core`-ի `toStyleDictionary`), պահում է բնիկ-տեսակավորված թոկենները (գույներ, չափեր, թվեր), և հանձնում դրանք `@pantoken/sd-config`-ին: `platform`-ից `flutter`/`compose`-ի փոխանակումը վերամիջատեղ ունի նույն ուղին:
