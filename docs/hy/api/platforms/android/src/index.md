# android

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/android` — արտածել Instructure դիզայն թոքենները որպես Android ռեսուրսային XML:

Այն հարթեցնում է IR-ը կոնկրետ, միայնակ ռեժիմի արժեքներին (`@pantoken/core`-ի `toStyleDictionary`), ապա
արտածում `res/values/colors.xml` (գույն թոքեններ) և `res/values/dimens.xml` (չափսի թոքեններ) օգտագործելով
`@pantoken/sd-config`: Style Dictionary-ն կիրառում է Android փոխակերպումները (`#aarrggbb`, `dp`/`sp`):
