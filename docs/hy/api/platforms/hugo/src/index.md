# hugo

<span class="instui-pill -color-danger pantoken-doc-tag">Փորձարկումային</span>

`@pantoken/hugo` — արտանետել Instructure թոկենային ոճի թերթ Hugo կայքի համար:

Hugo-ն չունի ստանդարտ թեմայի փոփոխական պայման, այնպես որ սա թոկենները տրամադրում է որպես drop-in ակտիվ
`assets/`-ի ներքո (որտեղ Hugo Pipes / Dart Sass դրանք վերցնում են): Sass մասնակի և պարզ CSS ֆայլ
(`@pantoken/scss`-ից և `@pantoken/css`-ից), գումարած InstUI-տեսք արձակ ոճի թերթ (`@pantoken/components`-ից), որը ոճավորում է
բովանդակությունը `.pantoken-prose` շրջանում:
