# wordpress

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/wordpress` — Instructure դիզայն տոկենները որպես WordPress block-theme `theme.json`:

[toThemeJson](functions/toThemeJson.md)-ը փոխակերպում է ցանկացած IR; [themeJson](variables/themeJson.md)-ը պատրաստ `rebrand` փաստաթուղթ է: CLI-ն կարող է այն գրել թեմայի գրացուցակում՝ `pantoken generate wordpress --out ./my-theme`:
