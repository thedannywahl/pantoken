# jekyll

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/jekyll` — արտանետել Instructure թոկենային ոճի թերթ Jekyll կայքի համար:

Jekyll-ն չունի ստանդարտ թեմայի փոփոխական պայման, այնպես որ սա թոկենները տրամադրում է որպես drop-in ակտիվ:
Sass մասնակի `_sass/`-ի համար (import այն ձեր main ոճի թերթից) և պարզ CSS ֆայլ `assets/css/`-ի համար
(`@pantoken/scss`-ից և `@pantoken/css`-ից), գումարած InstUI-տեսք արձակ ոճի թերթ (`@pantoken/components`-ից), որը ոճավորում է
բովանդակությունը `.pantoken-prose` շրջանում:
