# canvas-theme-editor

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`@pantoken/canvas-theme-editor` — վերբեռնելու համար պատրաստ `theme.css`/`theme.js` Canvas LMS-ի Թեմա
Հետագրիչի համար, պանտոքեն-ի CDN-ում հյուսված CSS: Օգտագործված `@pantoken/scaffold`-ի
`canvas-theme-editor` հարթակից; նաև կարող օգտագործել ինքնուրույն:

`THEME_CSS`/`THEME_JS` jsDelivr-ի հայտնի, անյուղ ելք են — օգտագործել [buildTheme](functions/buildTheme.md), որ
բռնել այլ CDN մատակարար, պտուտ տարբերակ, կամ փոխել այլ պանտոքեն/երրորդ-կողմ ակտիվները:
