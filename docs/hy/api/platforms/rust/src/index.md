# rust

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/rust` — արտանետել Instructure դիզայն թոկենները որպես Rust հաստատուններ երկու գլխավոր բնիկ Rust GUI-ների համար. **egui** (`Color32`) և **iced** (`Color`): Գույները դառնում են շրջանակի գույն տեսակ. չափերը դառնում են `f32` (px): Վեբ-ռենդերված Rust UI (Tauri, Dioxus-web, Leptos, Yew) պետք է դրա փոխարեն օգտագործեն `@pantoken/css`:
