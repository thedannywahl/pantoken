# pantoken-ai

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`@pantoken/ai` — սպառողի կողմից նայված գործակալի ակտիվներ այն նախագծերի համար, որոնք _օգտագործում են_ pantoken (ոչ թե
անձամբ pantoken-ի մշակմանը):

Այն տեղադրում է `AGENTS.md`, `llms.txt`, խմբագիր/գործակալ կանոն ֆայլեր (Cursor, Copilot, Windsurf), և
Claude Code հմտություններ (`init-pantoken`, `create-pantoken-app`), գումարած [installAgentAssets](functions/installAgentAssets.md) /
[scaffoldAndInit](functions/scaffoldAndInit.md) / `pantoken-ai` CLI դրանք իջեցնել սպառողական շամ
սովորական ուղիներում:
