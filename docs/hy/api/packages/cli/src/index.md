# cli

<span class="instui-pill -color-warning pantoken-doc-tag">Բետա</span>

`@pantoken/cli` — `pantoken generate <target>`.

Արտանետում է ծնիկ և այլ non-npm դիզայն-token աղբյուր սպառողի repo-ում — թիրախները, որոնք չեն տեղավորվում npm-package մոդելում։ Այժմ աջակցվում են՝ `swift` (SPM `Package.swift` manifest stub-ի հետ, այսպես որ registry հրապարակումը հետո կազմաձևման վեր շրջում է), `android`, `compose`, `flutter`, `wordpress`, `vanilla`, `drupal`, `swatches`, `rust`, `icon-font`, `pendo`, `jekyll`, `hugo` և `mintlify`։
