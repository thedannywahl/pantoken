# vite

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/vite` — Vite plugin pantoken-ի համար:

Այն բացահայտում է երկու վիրտուալ մոդուլ այնպես, որ apps-ները կօգտագործեն tokens-ներ առանց մեծ packages-ներ ուղղակիորեն ներմուծելու
է, և կարող են ավտոմատ ներգրավել stylesheet-ը HTML entry-ի մեջ:

- `virtual:pantoken/css` — stylesheet տողը (լռելյայն export):
- `virtual:pantoken/tokens` — resolved token IR (`tokens` անունով + լռելյայն export):
