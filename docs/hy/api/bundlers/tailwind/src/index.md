# tailwind

<span class="instui-pill -color-danger pantoken-doc-tag">Փորձարկումային</span>

`@pantoken/tailwind` — Tailwind CSS նախածանց, որը քարտեզագրում է Instructure դիզայն tokens-ները թեմայի մեջ:

Յուրաքանչյուր token բացահայտ է `var(--instui-*)` տեղեկույցի համար (ոչ թե կոնկրետ արժեք), ուստի Tailwind
utilities ինչպես `bg-color-background-base` թեմային միջով նույն CSS custom properties-ներ
`@pantoken/css` արտանետում — light/dark և high-contrast բոլորը շարունակում են աշխատել:
