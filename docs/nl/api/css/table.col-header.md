# CSS: table.col-header

`th` — A column-header cell (InstUI `Table.ColHeader`); the default `th` styling, overridden by `table.row-header` for `th[scope="row"]`.

## Usage

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.col-header.css";
```

## Tokens consumed

| -------------------------------------------------------- | -------------- | ------------------------------ |

| `--instui-component-table-col-header-color`              | `<color>`      | `light-dark(#273540, #F2F4F5)` |
| `--instui-component-table-col-header-line-height`        | `<percentage>` | `125%`                         |
