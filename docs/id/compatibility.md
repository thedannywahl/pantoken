# Kompatibilitas

<!-- Dihasilkan oleh `vp run sync:compatibility`. Jangan sunting secara manual; jalankan writer dan commit. -->

Halaman ini mencatat sumber Instructure UI yang diselesaikan oleh build pantoken ini, dan konsumen mana yang menggunakannya. Versi target terpisah: hanya rilis yang terverifikasi yang diklaim, dan rilis yang lebih baru dari rilis terverifikasi terakhir memerlukan tinjauan. Regenerasi dengan `vp run sync:compatibility`; pemeriksaan `gate:compatibility` gagal jika menyimpang.

## Sumber hulu

## Meninjau rilis target

Alur kerja target-rilis mingguan membuka issue tinjauan untuk rilis WordPress stabil baru dan ekosistem dengan peer npm eksplisit. Untuk target lain, pemelihara memeriksa catatan rilis resmi platform setiap minggu dan membuka issue tinjauan secara manual; ketiadaan issue tidak berarti rilis baru didukung. Untuk memperluas klaim:

1. Periksa skema keluaran rilis atau perubahan integrasi dan adapter di tabel ini.
2. Jalankan perintah kompatibilitas adapter dengan rilis kandidat, misalnya `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Perintah default membaca setiap entri `testedVersions` dari registri ini; lingkungan berpasangan menerima flag pendamping mereka.
3. Untuk kandidat yang ditemukan oleh feed, gunakan `vp run downstream:test`; upaya yang gagal disimpan di `scripts/release/downstream-compatibility.json`. Setelah tinjauan berhasil, jalankan `vp run downstream:bless --package @pantoken/name --version x.y.z` untuk memperbarui klaim.
4. Jalankan host nyata, compiler, atau pemeriksaan build minimal pada rilis baru. Pemetaan ulang format keluaran saat ini jika perlu; jangan menambahkan emitter format lama paralel.
5. Perbarui `scripts/release/target-compatibility.json` hanya setelah pemeriksaan lulus, lalu jalankan `vp run sync:compatibility`, regenerasi dokumentasi API berbahasa Inggris, dan tambahkan changeset. Rilis yang lebih baru tetap tertunda sampai perubahan yang ditinjau itu masuk. Dokumentasi terlokalisasi ditangani secara terpisah.
