# 变量: sideNavBar

> `const` **sideNavBar**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-side-nav-bar&gt;` — the styled shell of a vertical navigation rail. `minimized="true"` adds
the `-minimized` modifier (collapsed rail); the consumer slots the nav items.

## 示例

```html
<instui-side-nav-bar>
  <a href="/dashboard">Dashboard</a>
  <a href="/courses">Courses</a>
</instui-side-nav-bar>
```
