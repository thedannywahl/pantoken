# API 参考

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## 从这里开始

| 区域 | 描述 |
| --- | --- |
| [CSS API reference](/zh-Hans/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/zh-Hans/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/zh-Hans/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/zh-Hans/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
