# 函数: syncInvoker()

> **syncInvoker**(`host`): `void`

Mirror the host's invoker attributes onto its inner `&lt;button&gt;`'s IDL properties, resolving ids
against the host's root so a shadow-DOM button can drive a light-DOM `[popover]`/command target.

## 参数

### host

`HTMLElement`

## 返回值

`void`
