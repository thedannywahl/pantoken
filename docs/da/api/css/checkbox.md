# CSS: checkbox

`.instui-checkbox` — Et indfødt checkbox og dets etiket, eller en switch via `-variant-toggle`.

Sæt `el.indeterminate = true` i JavaScript for at vise det blandede tilstandsbindestreg; markeringen auto-kontrasterer mod fyldningen — hvid på mørk fyldning, næsten sort på en lys. Indstiller også sin egen `gap` mellem kontrollen og dens etiket; kæding af en `-gap-*` spacing utility modifier overrider denne indbyggede værdi.

**Kilde:** [checkbox.css](https://github.com/thedannywahl/pantoken/blob/main/formats/components/src/components/checkbox/checkbox.css)

## Accessibility

Et naturligt `<input type="checkbox">` styrer `:checked`, `:indeterminate` og `:disabled`; sæt `el.indeterminate = true` i JavaScript for det blandede tilstand, og bemærk at `-readonly` er kun styling da afkrydsningsfelter ikke har naturligt readonly attribut.

## Usage

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/checkbox.css";
```

## Examples

```html
<label class="instui-checkbox --display-block --mb-sm">
  <input type="checkbox" checked />Checkbox
</label>
<label class="instui-checkbox -variant-toggle"> <input type="checkbox" />Toggle </label>
```

## Modifiers

| Modifier                  | Description                                             |
| ------------------------- | ------------------------------------------------------- |
| `.-invalid`               | Ugyldigt (fejl) tilstand.                               |
| `.-label-placement-end`   | Placer etiketten efter kontrollen.                      |
| `.-label-placement-start` | Placer etiketten før kontrollen.                        |
| `.-label-placement-top`   | Placer etiketten over kontrollen.                       |
| `.-readonly`              | Skrivebeskyttet tilstand.                               |
| `.-required`              | Vis det påkrævede felt-asterisk ved siden af etiketten. |
| `.-size-large`            | Stor. Langt-form alias af `-size-lg`.                   |
| `.-size-lg`               | Stor.                                                   |
| `.-size-sm`               | Lille.                                                  |
| `.-size-small`            | Lille. Langt-form alias af `-size-sm`.                  |
| `.-variant-toggle`        | Gengiv som en kontakt i stedet for en kasse.            |

## Parts

| Part        | Description                  |
| ----------- | ---------------------------- |
| `.asterisk` | Det påkrævede felt-asterisk. |

## Pseudo-elements

| Pseudo-element | Description                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `::after`      | På `-variant-toggle`, tilstandsglyfen rider på håndtaget: et X når det er slået fra, en markering når det er slået på.                      |
| `::before`     | Det maskerede markeringsbindestreg eller bindestreg glyf centreret i kassen; på `-variant-toggle` bliver det i stedet det glidende håndtag. |
