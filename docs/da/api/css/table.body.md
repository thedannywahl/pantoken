# CSS: table.body

`tbody` — Tabelens datarække-gruppe (InstUI `Table.Body`).

Forælderen `table`'s `-layout-stacked` modifier restyler dette medlem — se `table`'s egen dokumentation for denne modifier.

## Usage

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.body.css";
```
