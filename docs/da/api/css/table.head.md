# CSS: table.head

`thead` — Tabellens header-rækkegruppe (InstUI `Table.Head`).

Forælderen `table`'s `-layout-stacked` modifier skjuler visuelt dette medlem (dets kolonnetitler vises pr. celle i stedet) — se `table`'s egen dokumentation for denne modifier.

## Brug

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.head.css";
```

## Forbrugte tokens

| Token | Type | Værdi |
| --- | --- | --- |
| `--instui-component-table-head-background` | `<color>` | `light-dark(#ffffff, #10141A)` |
