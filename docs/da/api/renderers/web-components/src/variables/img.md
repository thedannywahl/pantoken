# Variable: img

> `const` **img**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-img&gt;` — en token-stiliseret `&lt;img&gt;` bygget fra `src`/`alt`. `constrain` kortlægges til
`-constrain-&lt;value&gt;` (f.eks. `cover`, `contain`) og `display="block"` til `-display-block`.

## Example

```html
<instui-img src="/hero.jpg" alt="Campus" constrain="cover" display="block"></instui-img>
```
