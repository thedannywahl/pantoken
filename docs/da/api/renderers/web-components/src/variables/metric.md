# Variable: metric

> `const` **metric**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-metric&gt;` — en mærket statistik: en stor `value` over en mindre `label`. Begge kommer fra
attributter (escaped), ikke slots.

## Example

```html
<instui-metric value="1,024" label="Enrolled"></instui-metric>
```
