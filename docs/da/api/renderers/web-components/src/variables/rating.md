# Variabel: rating

> `const` **rating**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-rating&gt;` — en stjernebedømmelse med `role="img"`. `value` er antallet af fyldte stjerner, `max` det samlede antal (standard 5), og `label` tilsidesætter tilgænkelighadsnavnet (standard er `value/max`). Stjerner gengives som inline SVG-glyfader (solid = fyldt), skaleret til teksten.

## Eksempel

```html
<instui-rating value="4" max="5" label="4 out of 5 stars"></instui-rating>
```
