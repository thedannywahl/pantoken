# Variabel: iconButton

> `const` **iconButton**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-icon-button&gt;` — en ikon-kun, kvadratisk knap. `label` bliver knappens `aria-label`;
slottet indhold er glyphen (f.eks. en `&lt;instui-icon&gt;`).

## Eksempel

```html
<instui-icon-button label="Close">
  <instui-icon name="x"></instui-icon>
</instui-icon-button>
```
