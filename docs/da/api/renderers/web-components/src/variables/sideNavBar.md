# Variabel: sideNavBar

> `const` **sideNavBar**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`&lt;instui-side-nav-bar&gt;` — det stiliseret skal af en lodret navigationsskinnestrækning. `minimized="true"` tilføjer modifikatoren `-minimized` (sammenfoldet skinnestrækning); forbrugeren slotter navigationselementerne.

## Eksempel

```html
<instui-side-nav-bar>
  <a href="/dashboard">Dashboard</a>
  <a href="/courses">Courses</a>
</instui-side-nav-bar>
```
