# astro

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`@pantoken/astro` — Astro / Starlight-integration til pantoken.

[InstUI](functions/InstUI.md) er et Starlight-plugin, der injicerer pantoken-stilarket (og ethvert plugin CSS, f.eks. en fokusring) i sidens head. Det porter fremgangsmåden af `starlight-theme-instui` over på den delte `@pantoken/css` pipeline, så det har ikke længere sin egen token resolver.
