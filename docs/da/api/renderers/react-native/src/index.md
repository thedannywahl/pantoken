# react-native

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/react-native` — Instructure-design-tokens som React Native `StyleSheet`-venlige
objekter. React Native har ingen CSS-variabler, så tokens er helt opløst til konkrete værdier:
farver forbliver hex-strenge, dimensioner bliver tal (dp), og ikoner er udelukket.
