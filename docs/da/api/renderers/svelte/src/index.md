# svelte

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/svelte` — Svelte-hjælpere over `@pantoken/web-components`.

`icon` er en Svelte-handling, der rendrer et Instructure-glyphe ind i et element. `readToken` læser en
løst `--instui-*`-værdi (SSR-sikker). De brugerdefinerede elementer fungerer også direkte når `register()`
har kørt.
