# shadcn

<span class="instui-pill -color-danger pantoken-doc-tag">Eksperimentel</span>

`@pantoken/shadcn` — tema shadcn/ui med Instructure tokens.

[toShadcnCss](functions/toShadcnCss.md) udsender en `:root` blok, der peger shadcn's CSS-variabler til `var(--instui-*)`.
Slip den ind sammen med `@pantoken/css` (som definerer de brugerdefinerede egenskaber), og shadcn-komponenter
tager Instructure-udseendet til sig. Ikoner justeres gratis — shadcn og Instructure bruger begge Lucide.
