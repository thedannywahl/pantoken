# angular

<span class="instui-pill -color-danger pantoken-doc-tag">Eksperimentel</span>

`@pantoken/angular` — Angular-hjælpere over `@pantoken/web-components`.

Kald [registerPantokenElements](functions/registerPantokenElements.md) under bootstrap, og tilføj `CUSTOM_ELEMENTS_SCHEMA` til den
komponent/modul, der bruger `&lt;instui-icon&gt;`. [readToken](functions/readToken.md) læser en opløst `--instui-*` værdi.
