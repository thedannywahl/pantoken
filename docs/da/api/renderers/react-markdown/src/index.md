# react-markdown

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/react-markdown` — gengiver Markdown med Instructure UI-komponenter og pantoken-ikoner.

Standardindlægget gengiver GitHub-Flavored Markdown, inline `:icon:` tokens (via
`@pantoken/rehype` + `@pantoken/icons`), farveprøver og GitHub-stilede advarsler. MDX-udbyderen
bor på `@pantoken/react-markdown/mdx`.
