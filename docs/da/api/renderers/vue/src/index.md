# vue

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/vue` — et Vue-plugin over `@pantoken/web-components`.

`install` registrerer de brugerdefinerede elementer og fortæller Vue's compiler at behandle `instui-*` tags som
brugerdefinerede elementer. `readToken` læser en løst `--instui-*` værdi (SSR-sikker).
