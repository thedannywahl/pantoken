# bootstrap

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/bootstrap` — tema Bootstrap 5 med Instructure tokens.

Peger Bootstraps `--bs-*` CSS-variabler mod `var(--instui-*)`. Slip det ind ved siden af `@pantoken/css` og Bootstrap-komponenter adopterer Instructure-udseendet, mens tema stadig flyder gennem de samme brugerdefinerede egenskaber.
