# Interface: TokenUtilityGroup

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Et sæt af tokens der alle kortlægges til en CSS-egenskab (f.eks. hver `--instui-font-weight-*` → `font-weight`).

## Properties

### property

> **property**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

CSS-egenskaben, som tokens sætter (f.eks. `"font-weight"`, `"border-radius"`, `"box-shadow"`).

---

### tokens

> **tokens**: readonly `string`[]

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Fuldstændige tokennavn (f.eks. `"--instui-font-weight-body-strong"`); `--instui-` halen bliver klassen.
