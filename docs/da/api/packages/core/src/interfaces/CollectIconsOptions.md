# Interface: CollectIconsOptions

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Muligheder, der kontrollerer, hvilke ikonkilder der er inkluderet.

## Egenskaber

### includeInstui?

> `optional` **includeInstui?**: `boolean`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Inkluder Instructure-forfattede (Custom) glyfer (standard: true).

***

### includeLucide?

> `optional` **includeLucide?**: `boolean`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Inkluder Lucide-glyfer, som `@instructure/ui-icons` eksponerer dem (standard: true).
