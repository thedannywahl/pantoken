# cli

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/cli` — `pantoken generate <target>`.

Udsender indfødt og andre ikke-npm-designtoken-kilder til en forbrugerlager — de mål, der ikke
passer npm-pakkemodellen. Understøttet nu: `swift` (med en SPM `Package.swift` manifeststub, så
registerobjektivering senere er et konfigflip), `android`, `compose`, `flutter`, `wordpress`,
`vanilla`, `drupal`, `swatches`, `rust`, `icon-font`, `pendo`, `jekyll`, `hugo` og `mintlify`.
