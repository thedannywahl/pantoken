# icons

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/icons` — en ergonomisk visning over IR'ets `&lt;image&gt;` tokens.

Dette er ikke en anden kilde; det filtrerer den kanoniske IR fra `@pantoken/tokens` til ikonerne og dekoder hver data-URI tilbage til inline SVG, hvilket afdækker en form tæt på `SimpleIconTokenData`, som markdown/rehype-brugere allerede bruger.
