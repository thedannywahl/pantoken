# Interface: RemoveOptions

Indstillinger for timeout-baseret fjernelse.

## Egenskaber

### timeout?

> `optional` **timeout?**: `number`

Millisekunder før afvisning. Standard til målets beregnede `--timeout`.

***

### transition?

> `optional` **transition?**: `"fade"` \| `"none"`

Afslutningsbehandling. Standard til `"fade"`, der matcher InstUI Alert.
