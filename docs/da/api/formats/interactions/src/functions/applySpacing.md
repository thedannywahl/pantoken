# Funktion: applySpacing()

> **applySpacing**(`host`): `void`

Anvend InstUI/CSS-afstandsattributter på `host` til inline-stil.

Administrerede egenskaber ryddes først, så fjernelse af en attribut fjerner dens stil.

## Parametre

### host

`HTMLElement`

## Returnerer

`void`
