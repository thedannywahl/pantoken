# Function: syncInvoker()

> **syncInvoker**(`host`): `void`

Spejl værtens invoker-attributter på dens indre `&lt;button&gt;`'s IDL-egenskaber, løs id'er
mod værtens rod, så en shadow-DOM-knap kan styre et light-DOM `[popover]`/command-mål.

## Parameters

### host

`HTMLElement`

## Returns

`void`
