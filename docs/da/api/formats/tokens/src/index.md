# tokens

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/tokens` — den kanoniske løste token-IR, leveret som statisk JSON.

Standardeksporten er `rebrand` tema; hvert tema er tilgængeligt efter navn og via
[byTheme](functions/byTheme.md). Raw Tokens Studio JSON ligger på `@pantoken/tokens/raw`.
