# icon-font

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/icon-font` — byg et installerbart Instructure-ikonfont (WOFF2 + TTF) med et matchende stylesheet og kodepunktkort. I modsætning til inline-SVG-stiene installeres en skrifttype på en enhed, så den fungerer i designapps og offline-kontekster, hvor webtooling ikke er tilgængelig.

Slag-baserede glyphs (Lucide) er tegnet til udfyldninger, så de renderes som rigtige skriftglyphs; fyldings-baserede glyphs (Instructure custom) passerer gennem.
