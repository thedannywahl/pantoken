# Interface: VisualDebugOptions

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Indstillinger for [visualDebug](../functions/visualDebug.md) plugin'et.

## Egenskaber

### color?

> `optional` **color?**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Farven på debug-omridset (standard: en lysende magenta via `--pantoken-visual-debug-color`).

***

### position?

> `optional` **position?**: `"append"` \| `"prepend"`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Hvor reglerne lander i forhold til stylesheet: `"append"` (standard) eller `"prepend"`.
