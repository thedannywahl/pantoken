# Interface: PageLayout

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Et startsidelivayout: en almindelig komposition af eksisterende komponenter, ingen nye CSS-vælgere.

## Properties

### name

> **name**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Stabil id, svarer til kildefilnavnet (f.eks. `"hero"`).

---

### title

> **title**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Etiket vist i en layoutvælger.

---

### html

> **html**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Rå HTML til layoutet, bygget fra `@pantoken/components` klasser.
