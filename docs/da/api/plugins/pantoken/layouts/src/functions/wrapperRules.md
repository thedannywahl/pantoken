# Funktion: wrapperRules()

> **wrapperRules**(`prefix?`): `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Byg wrapper-layout CSS'en (doc-kommentar + regler), og erstat `prefix` med `pfx-`-sentinelen.
Standard til `"instui-"` for det leverede stylesheet; pass `""` for et uprefixeret build.

## Parametre

### prefix?

`string` = `"instui-"`

## Returnerer

`string`
