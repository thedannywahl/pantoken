## Properties

### prefix?

> `optional` **prefix?**: `string` \| `null`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Klassepræfikset. En sand streng navngiver alle klasser (`"instui"` → `.instui-bg-…`); enhver falsk værdi
fjernar præfikset helt (`.bg-…`). Den leverede `primitives.css` er bygget med `"instui"`.
