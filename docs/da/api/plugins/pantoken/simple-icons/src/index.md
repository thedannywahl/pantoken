# simple-icons

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

`@pantoken/plugin-simple-icons` — bring Simple Icons brand glyphs ind i pantoken.

Pluginen definerer en `tokens` hook (udsted valgte brand glyphs som `&lt;image&gt;` tokens, så de flyder
til CSS og native også) *og* en `rehype` hook (løs `:brand:` koder ved rendering). Samme plugin,
hvert lag — den generaliserede form for `mcp-stack/portal` icon factory.
