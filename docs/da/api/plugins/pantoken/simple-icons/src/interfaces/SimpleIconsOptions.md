### slugs?

> `optional` **slugs?**: `string`[]

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Brand slugs til at udsted som `&lt;image&gt;` tokens på token-laget (standard: ingen).

> `optional` **registry?**: [`SimpleIconsRegistry`](../type-aliases/SimpleIconsRegistry.md)

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Simple Icons registeret (standard: `simple-icons` pakken, indlæst dovilt).

***

### prefix?

> `optional` **prefix?**: `string`

<span class="instui-pill -color-warning pantoken-doc-tag">Beta</span>

Token-name præfikset (standard: `--instui-icon-`).
