# next

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/next` — en Next.js-konfiguration adapter.

Instructure UI leverer ESM-pakker, som Next skal transpilere (`transpilePackages`), det nr. 1 papirsnit ved kørsel af InstUI på Next. `withPantoken` fletter InstUI-pakkerne ind i denne liste. Omslut din `next.config`, og importer derefter `@pantoken/css` i dit root-layout for tokens.
