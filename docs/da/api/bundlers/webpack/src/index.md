# webpack

<span class="instui-pill -color-danger pantoken-doc-tag">Eksperimentel</span>

`@pantoken/webpack` — et Webpack plugin som udsender Instructure token stylesheettet som et build asset (standard `pantoken.css`), så du kan referere det fra dit HTML uden at importere den store pakke ind i et bundle.
