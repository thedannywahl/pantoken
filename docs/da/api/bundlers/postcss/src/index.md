# postcss

<span class="instui-pill -color-danger pantoken-doc-tag">Eksperimentel</span>

`@pantoken/postcss` — et PostCSS plugin som udvider et `@pantoken;` at-regel ind i det fulde
Instructure token stylesheet (`@property` registreringer + deklarationer). Skriv `@pantoken;` hvor
du vil have tokens defineret, og pluginet erstatter det ved build-tid.
