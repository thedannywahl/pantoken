# pantoken-ai

<span class="instui-pill -color-warning pantoken-doc-tag">Alpha</span>

`@pantoken/ai` — forbruger-orienterede agent-aktiver til projekter, der *bruger* pantoken (ikke til at udvikle pantoken selv).

Det leveres med en `AGENTS.md`, en `llms.txt`, editor/agent regel-filer (Cursor, Copilot, Windsurf), og Claude Code-færdigheder (`init-pantoken`, `create-pantoken-app`), plus [installAgentAssets](functions/installAgentAssets.md) / [scaffoldAndInit](functions/scaffoldAndInit.md) / `pantoken-ai` CLI til at droppe dem ind i et consumer-repo på konventionelle stier.
