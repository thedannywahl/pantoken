# rust

<span class="instui-pill -color-danger pantoken-doc-tag">Eksperimentel</span>

`@pantoken/rust` — udled Instructure design tokens som Rust-konstanter til de to vigtigste native Rust GUI'er: **egui** (`Color32`) og **iced** (`Color`). Farver bliver frameworkets farvetype; dimensioner bliver `f32` (px). Web-rendererede Rust UI'er (Tauri, Dioxus-web, Leptos, Yew) bør i stedet bruge `@pantoken/css`.
