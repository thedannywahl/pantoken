# wordpress

<span class="instui-pill -color-danger pantoken-doc-tag">Eksperimentel</span>

`@pantoken/wordpress` — Instructure designtokens som et WordPress block-theme `theme.json`.

[toThemeJson](functions/toThemeJson.md) konverterer enhver IR; [themeJson](variables/themeJson.md) er det færdige `rebrand` dokument. CLI'en kan skrive det til en temakatalog: `pantoken generate wordpress --out ./my-theme`.
