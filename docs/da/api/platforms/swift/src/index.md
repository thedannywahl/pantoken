# swift

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/swift` — udled Instructure design tokens som Swift via Style Dictionary.

Dette er pantokens native bevis: det udjævner IR til konkrete, enkelt-mode værdier (`@pantoken/core`'s `toStyleDictionary`), holder de naturligt-typede tokens (farver, dimensioner, tal) og sender dem til `@pantoken/sd-config`. Byt `platform` til `flutter`/`compose` for at genbruge den samme sti.
