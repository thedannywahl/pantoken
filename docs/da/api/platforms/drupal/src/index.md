# drupal

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/drupal` — udsend et Instructure-tema Drupal-undertema.

Producerer token-stylesheet (fra `@pantoken/css`) og et InstUI-look prosa-stylesheet (fra `@pantoken/components`, styling af indhold i en `.pantoken-prose` region), plus `*.info.yml` og `*.libraries.yml` som et Drupal 10/11-tema behøver for at indlæse dem. Drop filerne i `themes/custom/&lt;machine&gt;/`.
