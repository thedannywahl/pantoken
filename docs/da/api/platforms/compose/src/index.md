# compose

<span class="instui-pill -color-danger pantoken-doc-tag">Eksperimentel</span>

`@pantoken/compose` — udsend Instructure-designtokens som Jetpack Compose (Kotlin), via Style Dictionary. Det udfladder IR til konkrete, enkelt-tilstands værdier og bevarer de naturligt typerede tokens (farver, dimensioner, tal).
