# vanilla

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/vanilla` — Instructure design tokens som et Vanilla Forums Foundation `variables.json`.

[toVanillaVariables](functions/toVanillaVariables.md) konverterer enhver IR; [variables](variables/variables.md) er det færdigt `rebrand` objekt. Push det til et tema med Vanilla API: `PUT /themes/{themeID}/assets/variables.json`.
