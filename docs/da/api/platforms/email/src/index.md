# email

<span class="instui-pill -color-danger pantoken-doc-tag">Experimental</span>

`@pantoken/email` — Instructure-designtokens til HTML-email.

Email-klienter understøtter ikke CSS-brugerdefinerede egenskaber og fjerner ofte `&lt;style&gt;`, så tokens er fuldt opløst til konkrete værdier til inline-styling. Farver er hex; dimensioner beholder deres `px` enheder. Ikoner er udelukket. `light`/`dark` kort er nøgleret af camelCased-tokennavn.
