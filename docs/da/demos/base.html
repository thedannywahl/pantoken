Base-nulstilling

Dette resultat gengives med base.css indlæst først. Sidefladen, basistekstfarven og skrifttypen samt box-sizing stammer alle fra tokens – ingen egne regler er nødvendige.

Rene elementer overtager fornuftige standarder, som dette basislink, og alt er placeret på tokens sideflade. Skift temaet (eller lys/mørk), og overflade, tekst og link følger alle med.
