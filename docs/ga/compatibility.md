# Comhoiriúnacht

<!-- Ginte ag `vp run sync:compatibility`. Ná cuir in eagar de láimh; rith an scríbhneoir agus déan commit. -->

Taifeadann an leathanach seo na foinsí Instructure UI a réitíonn an tógáil pantoken seo uathu, agus na tomhaltóirí a úsáideann iad. Tá leaganacha sprice ar leith ann: ní mhaítear ach eisiúintí atá fíoraithe, agus ní mór athbhreithniú a dhéanamh ar eisiúintí níos déanaí ná an eisiúint dheireanach a fíoraíodh. Athghin é le `vp run sync:compatibility`; teipeann ar an tseiceáil `gate:compatibility` má imíonn sé ón bhfoinse.

## Athbhreithniú ar eisiúintí sprice

Osclaíonn an sreabhadh oibre seachtainiúil d’eisiúintí sprice saincheist athbhreithnithe maidir le heisiúintí cobhsaí nua WordPress agus le héiceachórais a bhfuil piara sainráite npm acu. I gcás spriocanna eile, seiceálann na cothaitheoirí nótaí eisiúna oifigiúla an ardáin gach seachtain agus osclaíonn siad saincheist athbhreithnithe de láimh; ní chiallaíonn easpa saincheiste go dtacaítear le heisiúint nua. Chun éileamh a leathnú:

1. Scrúdaigh scéimre aschuir na heisiúna nó athruithe comhtháthaithe, agus an cuibheoir sa tábla seo.
2. Rith ordú comhoiriúnachta an chuibheora leis an eisiúint iarrthach, mar shampla
   `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Léann an t-ordú réamhshocraithe gach
   iontráil `testedVersions` ón gclár seo; glacann timpeallachtaí péireáilte lena mbratacha compánaigh.
3. I gcás iarrthóirí a aimsítear tríd an bhfotha, úsáid `vp run downstream:test`; coinnítear iarrachtaí ar theip orthu in
   `scripts/release/downstream-compatibility.json`. Tar éis athbhreithniú rathúil, rith
   `vp run downstream:bless --package @pantoken/name --version x.y.z` chun an t-éileamh a nuashonrú.
4. Rith seiceáil ar an óstach, ar an tiomsaitheoir, nó ar an uirlis tógála féin ag an íosleagan agus ag an eisiúint nua. Athmhapáil an fhormáid aschuir reatha más gá; ná cuir eisitheoirí comhthreomhara d’fhormáidí oidhreachta leis.
5. Nuashonraigh `scripts/release/target-compatibility.json` tar éis do na seiceálacha pas a fháil amháin, ansin rith
   `vp run sync:compatibility`, athghin doiciméid API Bhéarla, agus cuir changeset leis. Fanann eisiúintí níos nuaí ar feitheamh go dtí go nglactar leis an athrú athbhreithnithe. Láimhseáiltear doiciméadú logánaithe ar leithligh.

## Dímheas

Comharthaí a bhain an fhoinse réamhtheachtach díobh ach a sheolann pantoken fós mar shims comhoiriúnachta. Coinnítear gach ceann ag obair go dtí go nglactar lena mhioneisiúint réamhtheachtach `Removed in`, agus ansin baintear an shim agus gearrtar mioneisiúint tomhaltóra. Cuireann shim ar aghaidh chuig comhartha `Replacement` nó reoitear an luach deireanach a bhí ar eolas aici.
