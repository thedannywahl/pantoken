# Comhoiriúnacht

<!-- Ginte ag `vp run sync:compatibility`. Ná cuir in eagar de láimh; rith an scríbhneoir agus déan commit. -->

Taifeadann an leathanach seo foinsí Instructure UI a réitíonn an tógáil pantoken astu, agus na tomhaltóirí a úsáideann iad. Coinnítear leaganacha sprice ar leithligh: ní mhaítear ach eisiúintí fíoraithe, agus caithfear athbhreithniú a dhéanamh ar eisiúintí níos nuaí ná an eisiúint dheireanach a fíoraíodh. Athghin é le `vp run sync:compatibility`; teipeann ar an tseiceáil `gate:compatibility` má bhíonn neamhréir ann.

## Athbhreithniú ar eisiúintí sprice

Osclaíonn sreabhadh oibre seachtainiúil na n-eisiúintí sprice saincheist athbhreithnithe le haghaidh eisiúintí cobhsaí nua WordPress agus éiceachórais a bhfuil piara sainráite npm acu. I gcás spriocanna eile, seiceálann na cothaitheoirí nótaí eisiúna oifigiúla an ardáin gach seachtain agus osclaíonn siad saincheist athbhreithnithe de láimh; ní chiallaíonn easpa saincheiste go dtacaítear le heisiúint nua. Chun éileamh a leathnú:

1. Scrúdaigh scéimre aschuir na heisiúna nó athruithe comhtháthaithe, agus an t-oiriúntóir sa tábla seo.
2. Rith ordú comhoiriúnachta an oiriúntóra leis an eisiúint iarrthach, mar shampla `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Léann an t-ordú réamhshocraithe gach iontráil `testedVersions` ón gclár seo; glacann timpeallachtaí péireáilte lena mbratacha comhlántacha.
3. I gcás iarrthóirí a aimsítear trí fhothaí, úsáid `vp run downstream:test`; coinnítear iarrachtaí ar theip orthu in `scripts/release/downstream-compatibility.json`. Tar éis athbhreithniú rathúil, rith `vp run downstream:bless --package @pantoken/name --version x.y.z` chun an t-éileamh a nuashonrú.
4. Rith seiceáil ar fhíoróstach, tiomsaitheoir nó uirlis tógála ag an eisiúint íosta agus ag an eisiúint nua. Athmhapáil an fhormáid aschuir reatha más gá; ná cuir astaitheoirí formáide leagáide comhthreomhara leis.
5. Nuashonraigh `scripts/release/target-compatibility.json` ach amháin tar éis do na seiceálacha pas a fháil, ansin rith `vp run sync:compatibility`, athghin doiciméid API Bhéarla, agus cuir changeset leis. Fanann eisiúintí níos nuaí ar feitheamh go dtí go nglactar leis an athrú athbhreithnithe. Déantar doiciméadú logánaithe a láimhseáil ar leithligh.

## Dímheas

Cuireann shim ar aghaidh chuig comhartha `Replacement` nó reoiteann sé a luach is déanaí atá ar eolas.
