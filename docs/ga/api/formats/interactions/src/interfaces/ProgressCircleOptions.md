# Comhéadan: ProgressCircleOptions

Options for the ProgressCircle mount animation.

## Airíonna

### animationDelay?

> `optional` **animationDelay?**: `number`

Milliseconds before the mount state is released. Defaults to computed `--animation-delay`.
