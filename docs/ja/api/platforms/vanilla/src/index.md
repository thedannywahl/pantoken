# vanilla

<span class="instui-pill -color-danger pantoken-doc-tag">実験的</span>

`@pantoken/vanilla` — Instructure design tokens as a Vanilla Forums Foundation `variables.json`.

[toVanillaVariables](functions/toVanillaVariables.md) converts any IR; [variables](variables/variables.md) is the ready-made `rebrand` object.
Push it to a theme with the Vanilla API: `PUT /themes/{themeID}/assets/variables.json`.
