# API リファレンス

bundler plugins, and design tooling.

| 領域 | 説明 |
| --- | --- |
| [CSS API reference](/ja/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |

| [renderers](/ja/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
