# एपीआई संदर्भ

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## यहाँ से शुरू करें

| क्षेत्र | विवरण |
| --- | --- |
| [CSS API reference](/hi/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/hi/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/hi/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/hi/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
