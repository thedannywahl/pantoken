# storybook

<span class="instui-pill -color-danger pantoken-doc-tag">प्रयोगात्मक</span>

`@pantoken/storybook` — a Storybook theme built from Instructure tokens.

[pantokenStorybookTheme](functions/pantokenStorybookTheme.md) returns a plain `ThemeVars`-shaped object (so `@storybook/theming`
stays an optional peer) with colours resolved concretely from the IR. Pass it to Storybook's
`manager`/`preview` theme.
