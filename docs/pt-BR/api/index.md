# Referência da API

bundler plugins, and design tooling.

| Área | Descrição |
| --- | --- |
| [CSS API reference](/pt-BR/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/pt-BR/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/pt-BR/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/pt-BR/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
