# Samhæfni

<!-- Búið til af `vp run sync:compatibility`. Ekki breyta handvirkt; keyrðu ritilinn og commit-aðu. -->

Þessi síða skráir hvaðan pantoken-smíðin sækir Instructure UI-heimildir og hvaða notendur
nota þær. Markútgáfur eru aðskildar: aðeins staðfestar útgáfur eru tilgreindar og fara þarf yfir
útgáfur sem eru nýrri en síðasta staðfesta útgáfa. Endurgerðu síðuna með `vp run sync:compatibility`; athugunin
`gate:compatibility` bregst ef hún rekur frá upprunanum.

## Upprunalegar heimildir

Hönnunartáknin, sérsniðnu Instructure-táknmyndirnar og Lucide-safnið mynda leysta tákn-IR-ið sem allir
pakkar nota. React-pakkarnir `@instructure/ui-*` eru eingöngu notaðir af
`@pantoken/react-markdown`.

## Yfirferð markútgáfa

Vikulegt verkflæði fyrir markútgáfur opnar yfirferðarmál fyrir nýjar stöðugar WordPress-útgáfur og
vistkerfi með skýrum npm-peer-háðum. Fyrir önnur markumhverfi fara viðhaldaðilar vikulega yfir opinberar
útgáfuupplýsingar vettvangsins og opna yfirferðarmál handvirkt; það að mál vanti merkir ekki að ný
útgáfa sé studd. Til að útvíkka fullyrðingu:

1. Skoðaðu úttakssnið útgáfunnar eða breytingar á samþættingu og aðlögunina í þessari töflu.
2. Keyrðu samhæfniskipun aðlögunarinnar með mögulegu nýju útgáfunni, til dæmis
   `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Sjálfgefna skipunin les allar
   `testedVersions` færslur úr þessari skrá; pöruð umhverfi taka við fylgilöggum.
3. Notaðu `vp run downstream:test` fyrir útgáfur sem fundust í gagnastraumi; misheppnaðar tilraunir eru varðveittar í
   `scripts/release/downstream-compatibility.json`. Eftir að yfirferð hefur tekist skaltu keyra
   `vp run downstream:bless --package @pantoken/name --version x.y.z` til að uppfæra fullyrðinguna.
4. Keyrðu athugun með raunverulegu hýsingarumhverfi, þýðanda eða smíðaverkfæri á lágmarksútgáfunni og
   nýju útgáfunni. Varpaðu núverandi úttakssniði aftur ef þörf krefur; ekki bæta við samhliða úttakssniðum fyrir eldri útgáfur.
5. Uppfærðu `scripts/release/target-compatibility.json` aðeins þegar athuganirnar standast, keyrðu síðan
   `vp run sync:compatibility`, endurgerðu ensku API-skjölin og bættu við changeset. Nýrri útgáfur
   eru áfram í bið þar til yfirfarða breytingin er komin inn. Staðfærð skjöl eru meðhöndluð sérstaklega.
