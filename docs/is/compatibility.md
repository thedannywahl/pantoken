# Samhæfni

<!-- Búið til af `vp run sync:compatibility`. Ekki breyta handvirkt; keyrðu ritilinn og sendu breytinguna inn. -->

Þessi síða skráir hvaðan Instructure UI-heimildirnar sem þessi pantoken-smíði leysir úr koma og hvaða notendur nota þær. Markútgáfur eru aðskildar: aðeins fullyrt er um útgáfur sem hafa verið sannreyndar, og yfirfara þarf útgáfur sem eru nýrri en síðasta sannreynda útgáfa. Endurgerðu síðuna með `vp run sync:compatibility`; `gate:compatibility`-athugunin bregst ef hún víkur frá upprunanum.

## Yfirferð á markútgáfum

Vinnuflæði vikulegrar yfirferðar markútgáfa opnar yfirferðarmál fyrir nýjar stöðugar WordPress-útgáfur og vistkerfi með skýrum npm-jafningjapakka. Fyrir önnur markumhverfi yfirfara umsjónaraðilar opinberar útgáfuupplýsingar vettvangsins vikulega og opna yfirferðarmál handvirkt; að mál vanti merkir ekki að ný útgáfa sé studd. Til að víkka út fullyrðingu:

1. Skoðaðu úttakssnið útgáfunnar eða breytingar á samþættingu og millilagið í þessari töflu.
2. Keyrðu samhæfniskipun millilagsins með viðkomandi útgáfu, til dæmis `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Sjálfgefna skipunin les allar `testedVersions`-færslur úr þessari skrá; pöruð umhverfi taka við fylgifánum sínum.
3. Fyrir útgáfur sem fundust í gagnastraumum skaltu nota `vp run downstream:test`; misheppnaðar tilraunir eru varðveittar í `scripts/release/downstream-compatibility.json`. Eftir að yfirferð hefur tekist skaltu keyra `vp run downstream:bless --package @pantoken/name --version x.y.z` til að uppfæra fullyrðinguna.
4. Keyrðu raunverulega athugun á hýsingarumhverfi, þýðanda eða smíðaverkfæri með lágmarksútgáfunni og nýju útgáfunni. Varpaðu núverandi úttakssniði aftur ef þess þarf; ekki bæta við samhliða útgefendum fyrir eldri snið.
5. Uppfærðu `scripts/release/target-compatibility.json` aðeins eftir að athuganir standast, keyrðu síðan `vp run sync:compatibility`, endurgerðu ensku API-skjölin og bættu við changeset. Nýrri útgáfur eru áfram í bið þar til yfirfarið breytingasafn nær inn. Staðfærð skjöl eru meðhöndluð sérstaklega.
