# Samhæfni

<!-- Búið til af `vp run sync:compatibility`. Ekki breyta handvirkt; keyrðu ritilinn og commit-aðu. -->

Þessi síða skráir hvaðan pantoken-smíðin sækir Instructure UI-heimildir og hvaða notendur nýta þær. Markútgáfur eru aðskildar: aðeins staðfestar útgáfur eru tilgreindar og yfirfara þarf útgáfur sem eru nýrri en síðasta staðfesta útgáfa. Endurmyndaðu síðuna með `vp run sync:compatibility`; athugunin `gate:compatibility` bregst ef hún víkur frá upprunanum.

## Yfirferð á markútgáfum

Vinnuflæðið fyrir markútgáfur opnar vikulega yfirferðarmál fyrir nýjar stöðugar WordPress-útgáfur og vistkerfi með skýrri npm-jafningjafærslu. Fyrir önnur markumhverfi fara umsjónaraðilar vikulega yfir opinberar útgáfuupplýsingar kerfisins og opna yfirferðarmál handvirkt; að ekkert mál sé opið þýðir ekki að ný útgáfa sé studd. Til að bæta við fullyrðingu:

1. Skoðaðu úttakssnið útgáfunnar eða breytingar á samþættingu og millistykkið í þessari töflu.
2. Keyrðu samhæfniskipun millistykkisins með mögulegu útgáfunni, til dæmis `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Sjálfgefin skipun les allar `testedVersions` færslur úr þessari skrá; pöruð umhverfi taka við fylgifánum.
3. Notaðu `vp run downstream:test` fyrir mögulegar útgáfur sem fundust í straumi; misheppnaðar tilraunir eru varðveittar í `scripts/release/downstream-compatibility.json`. Eftir árangursríka yfirferð skaltu keyra `vp run downstream:bless --package @pantoken/name --version x.y.z` til að uppfæra fullyrðinguna.
4. Keyrðu athugun með raunverulegu hýsingarumhverfi, þýðanda eða smíðaverkfæri á lágmarksútgáfunni og nýju útgáfunni. Varpaðu núverandi úttakssniði aftur ef þörf krefur; ekki bæta við samhliða úttakssniðum fyrir eldri útgáfur.
5. Uppfærðu `scripts/release/target-compatibility.json` aðeins eftir að athuganir standast, keyrðu síðan `vp run sync:compatibility`, endurmyndaðu ensku API-skjölin og bættu við breytingaskrá. Nýrri útgáfur eru áfram í bið þar til yfirfarið breytingasafn sameinast. Staðfærð skjöl eru meðhöndluð sérstaklega.
