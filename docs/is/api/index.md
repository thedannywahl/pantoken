# API tilvísun

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## Byrja hér

| Svæði | Lýsing |
| --- | --- |
| [CSS API reference](/is/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/is/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/is/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/is/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
