# מדריך API

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## התחל כאן

| אזור | תיאור |
| --- | --- |
| [CSS API reference](/he/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/he/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/he/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/he/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
