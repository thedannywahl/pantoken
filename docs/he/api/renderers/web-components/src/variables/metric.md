# משתנה: metric

> `const` **metric**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">אלפא</span>

`&lt;instui-metric&gt;` — a labelled statistic: a large `value` over a smaller `label`. Both come from
attributes (escaped), not slots.

## דוגמה

```html

```
