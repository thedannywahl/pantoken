# ממשק: CollectIconsOptions

<span class="instui-pill -color-warning pantoken-doc-tag">בטא</span>

Options controlling which icon sources are included.

## תכונות

### includeInstui?

> `optional` **includeInstui?**: `boolean`

<span class="instui-pill -color-warning pantoken-doc-tag">בטא</span>

Include Instructure-authored (Custom) glyphs (default: true).

***

### includeLucide?

> `optional` **includeLucide?**: `boolean`

<span class="instui-pill -color-warning pantoken-doc-tag">בטא</span>

Include Lucide glyphs as `@instructure/ui-icons` exposes them (default: true).
