# CSS: primitives

`.instui-bg-primitive-color-white` — Opt-in utility classes for the raw primitive palette: `.instui-bg-`/`fg-`/`border-primitive-color-&lt;name&gt;` paint a colour from the primitive colour tokens, plus `font-family`/`font-weight` utilities for the primitive font tokens. Kept out of the semantic utilities so overrides there stay semantic-only.

**Group:** Plugins · **Source:** [generate.ts](https://github.com/thedannywahl/pantoken/blob/main/plugins/pantoken/primitives/scripts/generate.ts)

## Uso

```css
@import "@pantoken/plugin-primitives/primitives.css";
```

## Ejemplos

```html
<div class="instui-bg-primitive-color-white instui-fg-primitive-color-aurora-aurora70">Primitive-painted box.</div>
```
