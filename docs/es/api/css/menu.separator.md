# CSS: menu.separator

`.separator` — A divider rule between items (InstUI `Menu.Separator`).

## Uso

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/menu.separator.css";
```

## Tokens consumidos

| Token | Tipo | Valor |
| --- | --- | --- |
| `--instui-component-menu-separator-background` | `<color>` | `light-dark(#E8EAEC, #2D3D49)` |
| `--instui-component-menu-separator-height` | `<length>` | `0.0625rem` |
| `--instui-component-menu-separator-margin-horizontal` | `<length>` | `0.75rem` |
| `--instui-component-menu-separator-margin-vertical` | `<length>` | `0rem` |
