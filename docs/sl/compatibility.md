# Združljivost

<!-- Ustvarjeno z `vp run sync:compatibility`. Ne urejajte ročno; zaženite zapisovalnik in spremembe potrdite. -->

Ta stran beleži vire Instructure UI, iz katerih ta gradnja pantokena razrešuje podatke, in katere odjemalce uporabljajo. Ciljne različice so ločene: navedene so samo preverjene izdaje, izdaje, novejše od zadnje preverjene, pa je treba pregledati. Stran znova ustvarite z `vp run sync:compatibility`; preverjanje `gate:compatibility` ne uspe, če se vsebina spremeni.

## Pregled ciljnih izdaj

Tedenski potek dela za ciljne izdaje odpre zahtevek za pregled novih stabilnih izdaj WordPressa in ekosistemov z izrecnim npm peer odvisnostnim paketom. Za druge cilje vzdrževalci vsak teden pregledajo uradne opombe ob izdajah platforme in ročno odprejo zahtevek za pregled; odsotnost zahtevka ne pomeni, da je nova izdaja podprta. Če želite razširiti trditev:

1. Preglejte izhodno shemo izdaje oziroma spremembe integracije ter adapter v tej tabeli.
2. Zaženite ukaz za preverjanje združljivosti adapterja s kandidatno izdajo, na primer
   `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Privzeti ukaz prebere vsak vnos `testedVersions` iz tega registra; seznanjena okolja sprejmejo zastavice za spremljevalne različice.
3. Za kandidate, odkrite prek vira, uporabite `vp run downstream:test`; neuspešni poskusi se ohranijo v `scripts/release/downstream-compatibility.json`. Po uspešnem pregledu zaženite `vp run downstream:bless --package @pantoken/name --version x.y.z`, da posodobite trditev.
4. Izvedite preverjanje s pravim gostiteljem, prevajalnikom ali orodjem za gradnjo za najnižjo in novo izdajo. Po potrebi prilagodite trenutno izhodno obliko; ne dodajajte vzporednih oddajnikov za zastarele oblike.
5. Posodobite `scripts/release/target-compatibility.json` šele, ko so preverjanja uspešna, nato zaženite `vp run sync:compatibility`, znova ustvarite angleško dokumentacijo API-ja in dodajte changeset. Novejše izdaje ostanejo v čakanju, dokler pregledana sprememba ni združena. Lokalizirana dokumentacija se ureja ločeno.

## Zastaranja

Žetoni, ki jih je izvorni sistem opustil, pantoken pa jih še vedno ponuja kot združljivostni nadomestek. Vsak ostane delujoč do sprejetja izvorne manjše različice `Removed in`; takrat se nadomestek odstrani in pripravi se manjša izdaja odjemalca.
