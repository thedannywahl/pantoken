# Funkcija: applySpacing()

> **applySpacing**(`host`): `void`

Apply InstUI/CSS spacing attributes on `host` to inline style.

Managed properties are cleared first, so removing an attribute removes its style.

## Parametri

### host

`HTMLElement`

## Vrne

`void`
