# Funkcja: initTruncateAuto()

> **initTruncateAuto**(`host`, `target`, `options?`): [`TruncateAutoHandle`](../interfaces/TruncateAutoHandle.md)

Keep `--lines` in sync with available height for an auto-clamped truncate target.

- CSS usage: pass the same element as `host` and `target`.
- Web-component usage: pass custom-element host + shadow truncate target span.

## Parametry

### host

`HTMLElement`

### target

`HTMLElement`

### options?

[`TruncateAutoOptions`](../interfaces/TruncateAutoOptions.md)
