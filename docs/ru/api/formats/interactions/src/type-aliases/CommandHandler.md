# Псевдоним типа: CommandHandler

> **CommandHandler** = (`command`, `source`) => `void`

Callback invoked when a `command` event (or fallback click) resolves to a target.

## Параметры

### command

`string`

### source

`Element` \| `null`

## Возвращаемое значение

`void`
