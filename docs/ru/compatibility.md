# Совместимость

<!-- Сгенерировано с помощью `vp run sync:compatibility`. Не редактируйте вручную; запустите генератор и сохраните изменения. -->

На этой странице указаны источники Instructure UI, из которых собирается эта версия pantoken, и потребители, которые их используют. Для разных целей указаны отдельные версии: заявлены только проверенные релизы, а релизы новее последнего проверенного требуют проверки. Пересоздайте страницу с помощью `vp run sync:compatibility`; проверка `gate:compatibility` завершается с ошибкой, если данные устарели.

## Проверка целевых релизов

Еженедельный процесс проверки целевых релизов создаёт задачу для проверки новых стабильных версий WordPress и экосистем с явно указанным npm peer. Для остальных целевых платформ сопровождающие еженедельно проверяют официальные примечания к релизам и вручную создают задачу; отсутствие задачи не означает, что новый релиз поддерживается. Чтобы расширить заявление о совместимости:

1. Изучите схему вывода релиза или изменения интеграции и адаптер в этой таблице.
2. Запустите команду проверки совместимости адаптера с предполагаемым релизом, например
   `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. По умолчанию команда считывает все записи
   `testedVersions` из этого реестра; для парных сред предусмотрены соответствующие флаги.
3. Для кандидатов, найденных по лентам обновлений, используйте `vp run downstream:test`; неудачные попытки сохраняются в
   `scripts/release/downstream-compatibility.json`. После успешной проверки запустите
   `vp run downstream:bless --package @pantoken/name --version x.y.z`, чтобы обновить заявление.
4. Проверьте работу в настоящей хост-среде, компиляторе или инструменте сборки на минимальной и новой версиях. При необходимости сопоставьте текущий формат вывода; не добавляйте параллельные генераторы устаревших форматов.
5. Обновляйте `scripts/release/target-compatibility.json` только после успешного прохождения проверок, затем запустите
   `vp run sync:compatibility`, пересоздайте документацию API на английском и добавьте changeset. Новые релизы остаются на рассмотрении, пока не будет внесено проверенное изменение. Локализованная документация обрабатывается отдельно.

## Устаревшие токены

Токены, удалённые upstream, которые pantoken по-прежнему поставляет в качестве слоя совместимости. Каждый из них продолжает работать до перехода на соответствующий upstream-релиз `Removed in`; после этого слой совместимости удаляется, а для потребителя выпускается минорная версия. Слой совместимости либо перенаправляет на токен `Replacement`, либо фиксирует его последнее известное значение.
