# Совместимость

<!-- Сгенерировано `vp run sync:compatibility`. Не редактируйте вручную; запустите генератор и сохраните изменения. -->

На этой странице указаны источники Instructure UI, из которых собирается pantoken, и потребители, которые их используют. Целевые версии указаны отдельно: заявлены только проверенные выпуски, а более новые выпуски, чем последний проверенный, требуют проверки. Пересоздайте страницу с помощью `vp run sync:compatibility`; проверка `gate:compatibility` завершится ошибкой, если данные устарели.

## Проверка целевых выпусков

Еженедельный процесс проверки целевых выпусков создаёт задачу для проверки новых стабильных выпусков WordPress и экосистем с явно указанной npm peer-зависимостью. Для других целевых платформ сопровождающие еженедельно проверяют официальные примечания к выпускам и вручную создают задачу; отсутствие задачи не означает поддержку нового выпуска. Чтобы расширить заявление о совместимости:

1. Изучите схему вывода или изменения интеграции в выпуске, а также адаптер из этой таблицы.
2. Запустите команду проверки совместимости адаптера с кандидатом на выпуск, например `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Команда по умолчанию считывает каждую запись `testedVersions` из этого реестра; для парных сред предусмотрены соответствующие флаги.
3. Для кандидатов, обнаруженных через ленту, используйте `vp run downstream:test`; неудачные попытки сохраняются в `scripts/release/downstream-compatibility.json`. После успешной проверки запустите `vp run downstream:bless --package @pantoken/name --version x.y.z`, чтобы обновить заявление.
4. Проверьте минимальный и новый выпуски в реальном хост-приложении, компиляторе или инструменте сборки. При необходимости сопоставьте текущий формат вывода; не добавляйте параллельные эмиттеры устаревших форматов.
5. Обновляйте `scripts/release/target-compatibility.json` только после успешных проверок, затем запустите `vp run sync:compatibility`, пересоздайте документацию API на английском и добавьте changeset. Новые выпуски остаются неподтверждёнными, пока соответствующее проверенное изменение не будет включено. Локализованная документация обновляется отдельно.

## Устаревшие токены

Токены, удалённые upstream, которые pantoken по-прежнему поставляет как слой совместимости. Каждый из них продолжает работать до принятия upstream-версии `Removed in`; после этого слой совместимости удаляется, а для потребителя выпускается минорное обновление.
