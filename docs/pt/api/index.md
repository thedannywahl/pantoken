# Referência da API

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## Comece aqui

| Área | Descrição |
| --- | --- |
| [CSS API reference](/pt/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/pt/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/pt/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/pt/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
