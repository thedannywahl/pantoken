# Référence API

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## Commencez ici

| Zone | Description |
| --- | --- |
| [CSS API reference](/fr/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/fr/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/fr/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/fr/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
