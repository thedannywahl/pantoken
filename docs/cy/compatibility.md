# Cydnawsedd

<!-- Cynhyrchwyd gan `vp run sync:compatibility`. Peidiwch â golygu â llaw; rhedwch yr ysgrifennwr a chadarnhewch. -->

Mae'r dudalen hon yn cofnodi'r ffynonellau Instructure UI y mae'r adeilad pantoken hwn yn eu datrys, a pha ddefnyddwyr sy'n eu defnyddio. Mae fersiynau targed ar wahân: dim ond datganiadau sydd wedi'u gwirio a hawlir, ac mae angen adolygu datganiadau sy'n fwy newydd na'r datganiad diwethaf a wiriwyd. Ail-gynhyrchwch hi gyda `vp run sync:compatibility`; mae'r gwiriad `gate:compatibility` yn methu os yw'n gwyro.

## Ffynonellau i fyny'r afon

## Adolygu datganiadau targed

Mae'r llif gwaith datganiadau targed wythnosol yn agor mater adolygu ar gyfer datganiadau WordPress sefydlog newydd ac ecosystemau sydd â chymar npm penodol. Ar gyfer targedau eraill, mae cynhalwyr yn gwirio nodiadau datganiadau swyddogol y platfform yn wythnosol ac yn agor mater adolygu â llaw; nid yw absenoldeb mater yn golygu bod datganiad newydd yn cael ei gefnogi. I ymestyn hawliad:

1. Archwiliwch gynllun allbwn y datganiad neu'r newidiadau integreiddio a'r addasydd yn y tabl hwn.
2. Rhedwch orchymyn cydnawsedd yr addasydd gyda'r datganiad ymgeisiol, er enghraifft
   `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Mae'r gorchymyn rhagosodedig yn darllen pob cofnod
   `testedVersions` o'r gofrestrfa hon; mae amgylcheddau pâr yn derbyn eu baneri ategol.
3. Ar gyfer ymgeiswyr a ddarganfuwyd drwy'r porthiant, defnyddiwch `vp run downstream:test`; cedwir ymdrechion aflwyddiannus yn
   `scripts/release/downstream-compatibility.json`. Ar ôl adolygiad llwyddiannus, rhedwch
   `vp run downstream:bless --package @pantoken/name --version x.y.z` i ddiweddaru'r hawliad.
4. Rhedwch wiriad gwesteiwr go iawn, crynhoydd, neu offeryn adeiladu ar y fersiwn isaf a'r datganiad newydd. Ail-fapiwch y fformat allbwn cyfredol os oes angen; peidiwch ag ychwanegu cynhyrchwyr fformat etifeddol cyfochrog.
5. Diweddarwch `scripts/release/target-compatibility.json` dim ond ar ôl i'r gwiriadau basio, yna rhedwch
   `vp run sync:compatibility`, ail-gynhyrchwch ddogfennaeth API Saesneg, ac ychwanegwch changeset. Bydd datganiadau mwy newydd yn parhau i aros hyd nes y bydd y newid a adolygwyd wedi'i uno. Ymdrinnir â dogfennaeth leol mewn ffordd ar wahân.

## Dibrisiadau

Cedwir pob un yn weithredol nes mabwysiadu ei fersiwn leiaf i fyny'r afon `Removed in`, ac yna caiff y shim ei ymddeol a rhyddheir fersiwn leiaf i ddefnyddwyr.
