# API-referens

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## Börja här

| Område | Beskrivning |
| --- | --- |
| [CSS API reference](/sv/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/sv/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/sv/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/sv/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
