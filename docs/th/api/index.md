# เอกสารอ้างอิง API

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## เริ่มที่นี่

| พื้นที่ | คำอธิบาย |
| --- | --- |
| [CSS API reference](/th/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/th/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/th/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/th/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
