หน้านี้บันทึกแหล่งที่มาของ Instructure UI ที่ pantoken บิลด์นี้แก้ไขการอ้างอิง และผู้ใช้ที่นำไปใช้ โดยแยกเวอร์ชันเป้าหมายออกจากกัน: ระบุเฉพาะรีลีสที่ตรวจสอบแล้ว และรีลีสที่ใหม่กว่าครั้งล่าสุดที่ตรวจสอบต้องได้รับการทบทวน สร้างหน้านี้ใหม่ด้วย `vp run sync:compatibility`; การตรวจสอบ `gate:compatibility` จะล้มเหลวหากข้อมูลคลาดเคลื่อน

## การทบทวนรีลีสเป้าหมาย

เวิร์กโฟลว์รีลีสเป้าหมายรายสัปดาห์จะเปิด issue สำหรับทบทวน WordPress รีลีสเสถียรใหม่และระบบนิเวศที่ระบุ npm peer ไว้ชัดเจน สำหรับเป้าหมายอื่น ผู้ดูแลจะตรวจสอบบันทึกรีลีสอย่างเป็นทางการของแพลตฟอร์มทุกสัปดาห์และเปิด issue เพื่อทบทวนด้วยตนเอง การไม่มี issue ไม่ได้หมายความว่ารองรับรีลีสใหม่ หากต้องการขยายข้ออ้าง:

1. ตรวจสอบสคีมาเอาต์พุตหรือการเปลี่ยนแปลงการผสานรวมของรีลีสนั้น และ adapter ในตารางนี้
2. เรียกใช้คำสั่งตรวจสอบความเข้ากันได้ของ adapter กับรีลีสที่กำลังพิจารณา เช่น
   `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. คำสั่งเริ่มต้นจะอ่านทุกรายการ `testedVersions` จากรีจิสทรีนี้; สภาพแวดล้อมที่จับคู่กันให้ใช้แฟล็กของสภาพแวดล้อมคู่กัน
3. สำหรับรีลีสที่ค้นพบจากฟีด ให้ใช้ `vp run downstream:test`; ความพยายามที่ล้มเหลวจะถูกเก็บไว้ใน `scripts/release/downstream-compatibility.json` หลังจากทบทวนสำเร็จ ให้เรียกใช้ `vp run downstream:bless --package @pantoken/name --version x.y.z` เพื่ออัปเดตข้ออ้าง
4. ตรวจสอบโฮสต์ คอมไพเลอร์ หรือเครื่องมือบิลด์จริงกับรีลีสขั้นต่ำและรีลีสใหม่ หากจำเป็น ให้ปรับรูปแบบเอาต์พุตปัจจุบัน; อย่าเพิ่ม emitter สำหรับรูปแบบเก่าควบคู่กัน
5. อัปเดต `scripts/release/target-compatibility.json` หลังจากการตรวจสอบผ่านแล้วเท่านั้น จากนั้นเรียกใช้ `vp run sync:compatibility` สร้างเอกสาร API ภาษาอังกฤษใหม่ และเพิ่ม changeset รีลีสที่ใหม่กว่าจะยังรออยู่จนกว่าการเปลี่ยนแปลงที่ผ่านการทบทวนจะถูกรวม เอกสารภาษาท้องถิ่นจัดการแยกต่างหาก
