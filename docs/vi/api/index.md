# Tham khảo API

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## Bắt đầu ở đây

| Khu vực | Mô tả |
| --- | --- |
| [CSS API reference](/vi/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/vi/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/vi/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/vi/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
