# Konpatibilite

<!-- Jenere pa `vp run sync:compatibility`. Pa modifye alamen; kouri zouti ki ekri li a epi fè commit. -->

Paj sa a anrejistre sous Instructure UI konstriksyon pantoken sa a rezoud, ansanm ak konsomatè ki sèvi ak yo. Vèsyon sib yo separe: nou deklare sèlman vèsyon nou verifye, epi vèsyon ki pi resan pase dènye vèsyon verifye a bezwen revizyon. Rejenere paj la avèk `vp run sync:compatibility`; verifikasyon `gate:compatibility` la echwe si gen diferans.

## Revize vèsyon sib yo

Flux travay chak semèn pou vèsyon sib yo ouvri yon tikè revizyon pou nouvo vèsyon WordPress ki estab ak ekosistèm ki gen yon peer npm eksplisit. Pou lòt sib yo, moun k ap mentni yo verifye nòt vèsyon ofisyèl platfòm nan chak semèn epi yo ouvri yon tikè revizyon manyèlman; absans yon tikè pa vle di yo sipòte yon nouvo vèsyon. Pou elaji yon deklarasyon:

1. Egzamine chema rezilta vèsyon an oswa chanjman entegrasyon yo ansanm ak adaptè ki nan tablo sa a.
2. Kouri kòmand konpatibilite adaptè a avèk vèsyon kandida a, pa egzanp
   `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Kòmand pa defo a li chak antre `testedVersions` ki nan rejis sa a; anviwònman pè yo aksepte drapo konpayon yo.
3. Pou kandida dekouvri nan feed, sèvi ak `vp run downstream:test`; tantativ ki echwe yo konsève nan
   `scripts/release/downstream-compatibility.json`. Apre yon revizyon reyisi, kouri
   `vp run downstream:bless --package @pantoken/name --version x.y.z` pou mete deklarasyon an ajou.
4. Fè yon verifikasyon reyèl sou platfòm lame a, konpilatè a, oswa zouti konstriksyon an avèk vèsyon minimòm nan ak nouvo vèsyon an. Remape fòma rezilta aktyèl la si sa nesesè; pa ajoute lòt emetè fòma ansyen an paralèl.
5. Mete `scripts/release/target-compatibility.json` ajou sèlman apre verifikasyon yo reyisi, epi kouri
   `vp run sync:compatibility`, rejenere dokiman API ann anglè yo, epi ajoute yon changeset. Nouvo vèsyon yo rete an atant jiskaske chanjman revize sa a antre. Dokiman lokalize yo trete apa.

## Depresyasyon

Jeton amont yo retire ke pantoken toujou founi kòm mekanis konpatibilite. Chak ladan yo rete fonksyonèl jiskaske yo adopte vèsyon minè amont `Removed in` li a; lè sa a, yo retire mekanis la epi yo pibliye yon vèsyon minè pou konsomatè a.
