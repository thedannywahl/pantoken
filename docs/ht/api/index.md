# Referans API

bundler plugins, and design tooling.

| Zòn | Deskripsyon |
| --- | --- |
| [CSS API reference](/ht/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/ht/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/ht/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/ht/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
