# angular

<span class="instui-pill -color-danger pantoken-doc-tag">Eksperimantal</span>

`@pantoken/angular` — Angular helpers over `@pantoken/web-components`.

Call [registerPantokenElements](functions/registerPantokenElements.md) during bootstrap, and add `CUSTOM_ELEMENTS_SCHEMA` to the
component/module that uses `&lt;instui-icon&gt;`. [readToken](functions/readToken.md) reads a resolved `--instui-*` value.
