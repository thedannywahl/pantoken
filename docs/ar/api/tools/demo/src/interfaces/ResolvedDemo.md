# واجهة: ResolvedDemo

عرض توضيحي محلول: سمات iframe بالإضافة إلى الموفر الذي أنتجها.

## الخصائص

### provider

> **provider**: `string`

الموفر الذي أنتج التضمين (`url`, `self`, `stackblitz`, …).

***

### src

> **src**: `string`

عنصر iframe `src`.

***

### sandbox

> **sandbox**: `string`

سمة iframe `sandbox`.
