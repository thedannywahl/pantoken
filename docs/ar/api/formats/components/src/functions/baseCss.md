# دالة: baseCss()

> **baseCss**(): `string`

<span class="instui-pill -color-warning pantoken-doc-tag">بيتا</span>

إنشاء ورقة أنماط أساسية/إعادة تعيين اختيارية: الإعدادات الافتراضية للمستند على مستوى العالم من الرموز (حجم الصندوق، إعادة ضبط الـbody
، سطح الصفحة، لون/خط النص الأساسي، `color-scheme`، الرابط الأساسي)، تليها قواعد حلقة التركيز (focus-ring)
(إعداد افتراضي على مستوى المستند يستهدف العناصر القابلة للتركيز العارية). تعيش هنا فقط قواعد الحلقة *ذاتها* — خصائص
`--instui-focus-outline-*` المخصصة التي تقرأها تُوزَّع في ورقة الرموز (`@pantoken/css`)، لذلك
لم تعد `base.css` تُعيد تعريفها. حمّلها مرة واحدة، قبل أوراق المكونات والنصوص، عندما تكون
pantoken مالكة للصفحة.

## القيم المرجعة

`string`
