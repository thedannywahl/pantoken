# متغير: img

> `const` **img**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">ألفا</span>

`&lt;instui-img&gt;` — `&lt;img&gt;` بنمط توكن مبني من `src`/`alt`. يُطابق `constrain` إلى
`-constrain-&lt;value&gt;` (مثل `cover`, `contain`) و`display="block"` إلى `-display-block`.

## مثال

```html
<instui-img src="/hero.jpg" alt="Campus" constrain="cover" display="block"></instui-img>
```
