# متغير: avatar

> `const` **avatar**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">ألفا</span>

`&lt;instui-avatar&gt;` — صورة شخصية دائرية (أو مستطيلة). `variant` تُطابق `-color-&lt;variant&gt;`,
`size` تُطابق `-size-&lt;size&gt;`, و `shape="rectangle"` تُطابق `-shape-rectangle`; المحتوى المُدرج هو
الأحرف الأولى، أو `&lt;img&gt;` (استخدم `src` بالمسار المطلق/شبكة CDN) لعرض صورة.

## مثال

```html
<instui-avatar size="lg" margin="small">JS</instui-avatar>
<instui-avatar shape="rectangle" variant="green" margin="small">AB</instui-avatar>
```
