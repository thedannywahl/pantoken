أسماء العناصر الأساسية (غير المزودة بسابقة) التي يسجلها هذا الحزم. [register](../functions/register.md) ينشئ علامة لكل اسم تحت خيار `prefix` — `icon` → `&lt;instui-icon&gt;` بشكل افتراضي، أو `&lt;x-icon&gt;` لـ `{ prefix: "x" }`.
