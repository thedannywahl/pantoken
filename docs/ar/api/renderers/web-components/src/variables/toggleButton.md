# متغير: toggleButton

> `const` **toggleButton**: [`ElementDefinition`](../interfaces/ElementDefinition.md)

<span class="instui-pill -color-warning pantoken-doc-tag">ألفا</span>

`&lt;instui-toggle-button&gt;` — زر ذو حالتين. `pressed="true"` يعكس إلى `aria-pressed` الخاص بالزر;
المحتوى الموضوع في الفتحة هو التسمية.

## مثال

```html
<instui-toggle-button pressed="true">Bookmarked</instui-toggle-button>
```
