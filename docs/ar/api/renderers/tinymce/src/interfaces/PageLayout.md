# واجهة: PageLayout

تخطيط صفحة مبدئي: تركيب بسيط للمكونات الموجودة، دون محددات CSS جديدة.

## الخصائص

### name

> **name**: `string`

معرّف ثابت، يطابق اسم الملف المصدر (مثال `"hero"`).

***

### title

> **title**: `string`

التسمية المعروضة في أداة اختيار التخطيط.

***

### html

> **html**: `string`

HTML خام للتخطيط، مبني من أصناف `@pantoken/components`.
