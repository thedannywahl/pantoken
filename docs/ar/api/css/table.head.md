# CSS: table.head

`thead` — مجموعة صف رأس الجدول (InstUI `Table.Head`).

محدد `-layout-stacked` الخاص بالـ `table` الأب يخفي هذا العنصر بصريًا (تظهر عناوين أعمدته داخل كل خلية بدلًا من ذلك) — انظر توثيق `table` نفسه لذلك المحدد.

## الاستخدام

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.head.css";
```

## الرموز المستهلكة

| رمز | نوع | قيمة |
| --- | --- | --- |
| `--instui-component-table-head-background` | `<color>` | `light-dark(#ffffff, #10141A)` |
