## Utilities

| Name                                                          | Class                                          | Summary                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [color](/ar/api/css/color.md)                                 | `.--text-danger`                               | أدوات لون دلالي: `.--bg-&lt;name&gt;` و `.--text-&lt;name&gt;` (بديل `.--color-&lt;name&gt;`) و `.--border-&lt;name&gt;` لوحة دلالية منسقة. كل واحد من هذه له أيضاً معدل بديل مرفق بالمكون (على سبيل المثال `-bg-danger` على أي `.instui-&lt;component&gt;`).                                                                                                                                                                                                |
| [cursor](/ar/api/css/cursor.md)                               | `.--cursor-pointer`                            | `cursor` كفئة عالمية قابلة للتكوين — `.--cursor-&lt;value&gt;` — قابلة للاستخدام مجردة أو مربوطة بأي مكون (`.instui-button.--cursor-pointer`).                                                                                                                                                                                                                                                                                                               |
| [gap](/ar/api/css/gap.md)                                     | `.--gap-md`                                    | أدوات Flex/grid `gap` على مقياس المسافات، تهجئة قصيرة (`--gap-sm`) أو طويلة (`--gap-small`). قابلة للاستخدام مجردة أو مربوطة بأي مكون (`.instui-view.--gap-sm`) — المكونات التي تعيّن بالفعل `gap` الخاص بها من رمز خاص بالمكون قد يتم تجاوزها.                                                                                                                                                                                                              |
| [icon](/ar/api/css/icon.md)                                   | `.instui-icon`                                 | نظام الأيقونات: تحديد حجم `.instui-icon` بالإضافة إلى الرسام المشترك `-icon-&lt;name&gt;` الذي يقنع الرمز الرسومي (في `currentColor`) قبل أي عنصر.                                                                                                                                                                                                                                                                                                           |
| [layout](/ar/api/css/layout.md)                               | `.--display-flex`                              | أدوات العرض والمحاذاة النصية — `.--display-&lt;value&gt;` و `.--text-align-&lt;value&gt;` — كفئات عالمية قابلة للتكوين، قابلة للاستخدام مجردة أو مربوطة بأي مكون.                                                                                                                                                                                                                                                                                            |
| [maskglobal](/ar/api/css/maskglobal.md)                       | `.--mask-overlay`                              | نسخة عالمية مزدوجة من معدلات الطبقة الشفافة للمكون `mask` — `--mask-overlay` و `--mask-fullscreen` و `--mask-blur` — قابلة للاستخدام مجردة أو مربوطة بأي مكون، بدون الالتفاف في عنصر `.instui-mask`.                                                                                                                                                                                                                                                         |
| [overflow](/ar/api/css/overflow.md)                           | `.--overflow-x-hidden`                         | `overflow-x`/`overflow-y` كفئات عالمية قابلة للتكوين — `.--overflow-x-&lt;value&gt;` / `.--overflow-y-&lt;value&gt;` — قابلة للاستخدام مجردة أو مربوطة بأي مكون.                                                                                                                                                                                                                                                                                             |
