# CSS: checkbox

`.instui-checkbox` — خانة اختيار أصلية وتسميتها، أو محول عبر `-variant-toggle`.

اضبط `el.indeterminate = true` في JavaScript لعرض شرطة الحالة المختلطة؛ علامة التحقق تتباين تلقائياً مع التعبئة - أبيض على تعبئة داكنة، أسود قريب على تعبئة فاتحة. كما يضبط `gap` الخاص به بين التحكم وتسميته؛ ربط معدّل أداة `-gap-*` المسافة يتجاوز تلك القيمة المدمجة.

**المصدر:** [checkbox.css](https://github.com/thedannywahl/pantoken/blob/main/formats/components/src/components/checkbox/checkbox.css)

## Accessibility

يدفع `<input type="checkbox">` الأصلي `:checked`، `:indeterminate`، و`:disabled`؛ اضبط `el.indeterminate = true` في JavaScript للحالة المختلطة، وانتبه إلى أن `-readonly` هي التنسيق فقط لأن خانات الاختيار ليس لديها سمة readonly أصلية.

## Usage

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/checkbox.css";
```

## Examples

```html
<label class="instui-checkbox --display-block --mb-sm">
  <input type="checkbox" checked />Checkbox
</label>
<label class="instui-checkbox -variant-toggle"> <input type="checkbox" />Toggle </label>
```

## Modifiers

| Modifier                  | Description                                |
| ------------------------- | ------------------------------------------ |
| `.-invalid`               | حالة غير صحيحة (خطأ).                      |
| `.-label-placement-end`   | ضع التسمية بعد التحكم.                     |
| `.-label-placement-start` | ضع التسمية قبل التحكم.                     |
| `.-label-placement-top`   | ضع التسمية فوق التحكم.                     |
| `.-readonly`              | حالة القراءة فقط.                          |
| `.-required`              | اعرض علامة النجمة حقل مطلوب بجانب التسمية. |
| `.-size-large`            | كبير. اسم مستعار طويل الشكل لـ `-size-lg`. |
| `.-size-lg`               | كبير.                                      |
| `.-size-sm`               | صغير.                                      |
| `.-size-small`            | صغير. اسم مستعار طويل الشكل لـ `-size-sm`. |
| `.-variant-toggle`        | قدم كمفتاح بدلاً من صندوق.                 |

## Parts

| Part        | Description             |
| ----------- | ----------------------- |
| `.asterisk` | علامة النجمة حقل مطلوب. |

## Pseudo-elements

| Pseudo-element | Description                                                                                                 |
| -------------- | ----------------------------------------------------------------------------------------------------------- |
| `::after`      | على `-variant-toggle`، حرف الحالة على المقبض: X عند الإيقاف، علامة عند التشغيل.                             |
| `::before`     | حرف العلامة أو الشرطة المخفية في المركز في الصندوق؛ على `-variant-toggle` يصبح المقبض المنزلق بدلاً من ذلك. |
