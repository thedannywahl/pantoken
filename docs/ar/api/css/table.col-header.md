# CSS: table.col-header

`th` — خلية رأس عمود (InstUI `Table.ColHeader`); نمط `th` الافتراضي، يتم استبداله بواسطة `table.row-header` لـ `th[scope="row"]`.

## الاستخدام

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/table.col-header.css";
```
