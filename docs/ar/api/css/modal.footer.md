# CSS: modal.footer

`.footer` — صف الإجراءات (InstUI `Modal.Footer`).

تعمل معدِّلات `-density-compact` و `-color-inverse` في العنصر الأب `modal` على إعادة تنسيق هذا العضو — راجع وثيقة `modal` نفسها للاطّلاع على تلك المعدِّلات.

## الاستخدام

```css
@import "@pantoken/components/components.css";
@import "@pantoken/components/modal.footer.css";
```
