# CSS: two-column

`div[class~="instui-two-column"]` — تخطيط ذو عمودين بمناطق محتوى يسار ويمين.

✅ استخدم تخطيط عمودين عندما:

- لديك منطقتا محتوى ذات أهمية متقاربة
- لمقارنة أو تباين مجموعتين من المحتوى جنبًا إلى جنب
- لبناء تخطيط مستجيب يتكدس على الأجهزة المحمولة
🚫 لا تستخدم تخطيط عمودين عندما:

- يهيمن عمود واحد على الصفحة — استخدم تخطيطًا غير متماثل بدلاً من ذلك
- لا يستفيد المحتوى من العرض جنبًا إلى جنب

## سهولة الوصول

- تأكد من أن كلا العمودين يمكن إدراكهما واستخدامهما على مشاهد عرض ضيقة
- استخدم معالم دلالية (مثل `&lt;section&gt;`) لتغليف محتوى العمود
- حافظ على مساحة وتباين كافيين بين العمودين

## الاستخدام

```css
@import "@pantoken/plugin-layouts/layouts.css";
```
