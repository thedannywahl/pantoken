# API reference

يغطي مرجع API pantoken المكتبات الأساسية ومُصدرات الصيغة والأهداف الأساسية والمُرجعات وملحقات المجمّع وأدوات التصميم.

## Start here

| Area                              | Description                                                                        |
| --------------------------------- | ---------------------------------------------------------------------------------- |
| [CSS API reference](/ar/api/css/) | فئات المكونات والأدوات والقواعد والإعلانات والسلوك الذي يدعمه الرموز في CSS.       |
| [packages](/ar/api/packages/)     | العقود الأساسية ومساعدو خط الأنابيب (model, core, utils, plugin-kit, CLI).         |
| [renderers](/ar/api/renderers/)   | التكاملات الخاصة بالإطار (React, Vue, Svelte, Storybook, وغيرها).                  |
| [platforms](/ar/api/platforms/)   | مخرجات النظام الأساسي المُنشأة (Swift, Compose, Flutter, Android, WordPress, إلخ). |

| Group                           | Description                                                                       |

| [tools](/ar/api/tools/)         | واجهات برمجة تطبيقات الأدوات الداخلية المستخدمة بواسطة خطوط الإنتاج والمستندات.   |
