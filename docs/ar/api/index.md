# مرجع واجهة برمجة التطبيقات

مرجع واجهة برمجة تطبيقات pantoken يشمل المكتبات الأساسية وملفات إخراج الصيغ وأهداف المنصات،
المُحَـرِّكات، وإضافات الباندل، وأدوات التصميم.

## ابدأ من هنا

| منطقة | الوصف |
| --- | --- |
| [CSS API reference](/ar/api/css/) | فئات المكونات، الأدوات المساعدة، القواعد، التصريحات، وسلوك CSS المدعوم بالرموز. |
| [packages](/ar/api/packages/) | العقود الأساسية ومساعدو خط الأنابيب (model, core, utils, plugin-kit, CLI). |
| [renderers](/ar/api/renderers/) | تكاملات مخصصة للأطر (React, Vue, Svelte, Storybook، والمزيد). |
| [platforms](/ar/api/platforms/) | مخرجات منصات مُولدة (Swift, Compose, Flutter, Android, WordPress، إلخ). |

## تصفح حسب المجموعة

| مجموعة | الوصف |

| [ai](/ar/api/ai/) | أصول الوكلاء وحزم أدوات الذكاء الاصطناعي. |

| [formats](/ar/api/formats/) | مخرجات صيغ الرموز/الأيقونات القابلة للاستيراد (CSS, SCSS, tokens, icons، والمزيد). |
| [packages](/ar/api/packages/) | واجهات برمجة تطبيقات الحزم الأساسية التي تُشغّل خط تحويل البيانات. |
| [platforms](/ar/api/platforms/) | نُظم بيئية مستهدفة مُولدة وصادرات مخصصة لوقت التشغيل. |

| [renderers](/ar/api/renderers/) | مُحَـرِّكات ومحوِّلات الإطارات ومواقع التوثيق. |
| [tools](/ar/api/tools/) | واجهات برمجة تطبيقات أدوات داخلية تُستخدم بواسطة خطوط توليد المحتوى والتوثيق. |
