# دالة: globalModifierSelector()

> **globalModifierSelector**(`p`, `name`): `string`

<span class="instui-pill -color-warning pantoken-doc-tag">بيتا</span>

بناء محدد مُعدِّل ذو فائدة عالمية: `:where(*).--name.--name.--name`. تكرار فئة المُعدِّل ثلاث مرات يعطي قاعدة تحديد الأولوية (0,3,0)، والتي تتفوق حتمًا على أي مركب مُعدِّل مكوَّن من فئتين حقيقيتين للمكوّن (`.instui-view.-mod`, 0,2,0) بغض النظر عن ترتيب المصدر — الغلاف `:where(*)` لا يساهم بأي تحديد أولوية خاص به، لذلك هو مجرد توثيق يُشير إلى أن هذا مُعدِّل عالمي، وليس شرطًا لتحديد النطاق. محدد الفئة العادي يطابق بالفعل العنصر المستقل (`--mt-lg` بدون فئة أخرى) أو يمكن ربطه بأي مكوّن، سواء من النواة أو مُنشَأ بواسطة مكوِّن إضافي، دون حاجة لعد لكل مكوّن على حدة. يستبدل النموذج القديم المكوَّن من فئة عارية بالإضافة إلى مركب مفصّل لكل مكوّن (`globalSelectors`/`chainTargets`)، الذي لم يكن يصل إلى المكوّنات المنشأة بواسطة الإضافات ولم يكن قابلاً للتوسع مع أدوات مساعدة ذات تصنيف عالٍ مثل الفراغات.
