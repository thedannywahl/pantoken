# Keserasian

<!-- Dijana oleh `vp run sync:compatibility`. Jangan edit secara manual; jalankan penulis dan buat commit. -->

Halaman ini merekodkan sumber Instructure UI yang digunakan oleh binaan pantoken ini dan pengguna yang menggunakannya. Versi sasaran adalah berasingan: hanya keluaran yang telah disahkan dinyatakan, dan keluaran yang lebih baharu daripada keluaran terakhir yang disahkan perlu disemak. Jana semula halaman ini dengan `vp run sync:compatibility`; semakan `gate:compatibility` akan gagal jika kandungannya berbeza.

## Sumber huluan

## Menyemak keluaran sasaran

Aliran kerja keluaran sasaran mingguan membuka isu semakan untuk keluaran WordPress stabil baharu dan ekosistem dengan peer npm yang jelas. Bagi sasaran lain, penyelenggara menyemak nota keluaran rasmi platform setiap minggu dan membuka isu semakan secara manual; ketiadaan isu tidak bermakna keluaran baharu disokong. Untuk meluaskan tuntutan:

1. Periksa skema output atau perubahan integrasi keluaran tersebut serta penyesuai dalam jadual ini.
2. Jalankan arahan keserasian penyesuai dengan keluaran calon, contohnya `vp run @pantoken/postcss#check:compatibility -- 8.5.29`. Arahan lalai membaca setiap entri `testedVersions` daripada registri ini; persekitaran berpasangan menerima flag pasangan masing-masing.
3. Bagi calon yang ditemukan melalui suapan, gunakan `vp run downstream:test`; percubaan yang gagal disimpan dalam `scripts/release/downstream-compatibility.json`. Selepas semakan berjaya, jalankan `vp run downstream:bless --package @pantoken/name --version x.y.z` untuk mengemas kini tuntutan.
4. Jalankan semakan hos, pengkompil atau alat binaan sebenar pada keluaran minimum dan keluaran baharu. Petakan semula format output semasa jika perlu; jangan tambah pemancar format legasi yang selari.
5. Kemas kini `scripts/release/target-compatibility.json` hanya selepas semakan berjaya, kemudian jalankan `vp run sync:compatibility`, jana semula dokumentasi API bahasa Inggeris dan tambah changeset. Keluaran yang lebih baharu kekal menunggu sehingga perubahan yang disemak itu digabungkan. Dokumentasi setempat dikendalikan secara berasingan.

## Penamatan

Token yang telah digugurkan daripada huluan tetapi masih dihantar oleh pantoken sebagai shim keserasian. Setiap token kekal berfungsi sehingga versi minor huluan `Removed in` diterima pakai; pada masa itu shim ditamatkan dan versi minor pengguna dikeluarkan. Shim sama ada memajukan kepada token `Replacement` atau membekukan nilai terakhir yang diketahui.
