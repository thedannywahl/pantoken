# API 參考

The pantoken API reference spans core libraries, format emitters, platform targets, renderers,
bundler plugins, and design tooling.

## 從這裡開始

| 區域 | 說明 |
| --- | --- |
| [CSS API reference](/zh-Hant/api/css/) | Component classes, utilities, rules, declarations, and token-backed CSS behavior. |
| [packages](/zh-Hant/api/packages/) | Core contracts and pipeline helpers (model, core, utils, plugin-kit, CLI). |
| [renderers](/zh-Hant/api/renderers/) | Framework-specific integrations (React, Vue, Svelte, Storybook, and more). |
| [platforms](/zh-Hant/api/platforms/) | Generated platform outputs (Swift, Compose, Flutter, Android, WordPress, etc.). |
