# Pantoken Roadmap

This roadmap describes the intended direction of Pantoken over approximately the next 12 months. It is intended as guidance rather than a guarantee. Priorities may change based on community feedback, security needs, or maintenance requirements.

## Planned Work

### Core Library

- Maintain a stable, well-documented public API.
- Continue improving TypeScript type safety.
- Improve documentation and usage examples.
- Improve test coverage and CI reliability.
- Maintain compatibility with supported Node.js LTS releases.

### Security

- Address reported vulnerabilities promptly.
- Continue dependency updates.
- Improve supply-chain security and OpenSSF compliance.

### Developer Experience

- Improve API documentation.
- Expand examples and tutorials.
- Improve error messages.
- Simplify contributor onboarding.

### Quality

- Increase automated testing.
- Improve performance where measurable benefits exist.
- Maintain backward compatibility whenever practical.

## Out of Scope

Pantoken does **not** currently intend to:

- Add runtime dependencies unless they provide significant value.
- Introduce breaking API changes without a major version release.
- Support deprecated Node.js versions.
- Implement features unrelated to token generation, parsing, or validation.
- Add framework-specific integrations unless there is clear community demand.

## Roadmap Updates

This roadmap is reviewed periodically and may be updated as project priorities evolve. Significant changes will be made through pull requests in the public repository.
