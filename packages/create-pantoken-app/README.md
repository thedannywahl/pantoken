# create-pantoken-app

pantoken resolves Instructure UI's design tokens and icons once, then turns that single model into
many small, publishable packages — CSS, React, Vue, Svelte, web components, native Swift and Kotlin,
and more. This is the fastest way to try it: scaffold a starter project with pantoken already
installed and wired in.

```sh
npx create-pantoken-app react
```

Platforms: `components` (plain HTML/CSS), `react`, `vue`, `svelte`, `web-components`, `angular`.

[Full docs](https://pantoken.iywahl.com) · [`@pantoken/scaffold`](https://www.npmjs.com/package/@pantoken/scaffold)
(the package this wraps, for `--dir` and programmatic use)
