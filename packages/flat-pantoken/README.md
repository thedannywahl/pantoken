# pantoken

Unscoped meta-package and CLI for pantoken: Instructure design tokens, icons, and components.

## Install

```sh
npm i pantoken
```

## Usage

```ts
import { tokens, components, icons } from "pantoken";
import "pantoken/css";
```

## CLI

```sh
npx pantoken create react
npx pantoken generate swift
npx pantoken add button
```
