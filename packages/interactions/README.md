# @pantoken/interactions

Shared browser interaction helpers for pantoken renderers.

## What It Includes

- Spacing attribute parsing and application helpers (`resolveSpace`, `spacingValue`, `applySpacing`, `SPACING_ATTRS`).
- Invoker Commands helpers (`makeOnCommand`, `syncInvoker`) used by shadow-DOM components.

The package is runtime-safe for browser bundles and has no Node dependencies.
